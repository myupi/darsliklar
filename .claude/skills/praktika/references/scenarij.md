# Сценарий практики (шаги Б–В)

## 1. Лесенка письма под тему

Постоянная последовательность заказчика:

| Ступень | Что делает ученик | Вид редактора (`spec.kind` в каркасе) |
|---|---|---|
| Готовый код → изменить содержимое | Меняет текст в правильно собранном коде, сам выбирая место | `fields` — поля прямо в строках кода |
| Написать строку | Пишет одну строку целиком: теги и содержимое | `line` — одна строка внутри неизменяемой рамки |
| Написать блок | Пишет несколько строк: открывающий тег, содержимое, закрывающий | `block` — область из нескольких строк |
| Исправить документ | Находит, чего не хватает или что стоит не там, и правит | `doc` — весь документ редактируется |
| Написать по схеме с нуля | Пишет документ (фрагмент) по чертежу, без готового кода | `doc` с `big: true` — большой редактор |

Лесенка подстраивается под тему: не каждое умение требует всех ступеней. Но в практике должны быть и правка, и строка, и блок, и исправление, и своё с нуля.

**Материал** (заказчик, 16.10.2026; подробно — `trebovaniya.md`, «Материал практики»):
- лесенку проходят умения **своего урока**, это примерно три задания из четырёх;
- прошлые уроки дают опору (готовый документ вокруг) и 1–2 задания-смеси;
- финал объединяет всё.

### Как это выглядит для следующих тем — варианты для размышления, не шаблон

- **Урок 2 (`h1–h6`, `p`, `b`, `i`):**
  - поменять текст заголовка и абзаца;
  - написать строку `<h2>…</h2>`;
  - написать абзац с выделенным словом;
  - смесь с уроком 1: «на вкладке — одно, на странице крупно — другое» (`title` и `h1`);
  - исправить документ (не тот уровень заголовка, незакрытый `p`, `</b>` не там; смесь — и не закрыт `body`);
  - своя страница целиком: документ урока 1 плюс «h1 → p → h2 → p».
- **Урок 3 (`ul`, `ol`, `li`):**
  - поменять пункты;
  - написать строку `<li>`;
  - написать список из трёх пунктов;
  - исправить (пункт вне списка, `ol` вместо `ul`, номера руками, незакрытый список);
  - свой список по схеме.
- **Урок 4 (`a`, `href`):**
  - поменять текст ссылки и адрес;
  - написать строку `<a href="…">…</a>`;
  - написать меню из ссылок;
  - починить сломанные ссылки;
  - свой мини-сайт: две страницы, связанные ссылками.
- **Урок 5 (`img`, `src`, `alt`):**
  - поменять `alt`;
  - написать строку `img`;
  - карточка с картинкой и подписью;
  - починить пустую рамку;
  - своя галерея.

## 2. Операция и карта

- **Своя операция для каждой практики:**
  - в 01p уже были «база роботов» (прежняя) и «бумажная улица» (эталон) — не повторять;
  - сюжет связан с темой (заголовки — газета или афиша клуба; списки — склад или маршрут; ссылки — квест по комнатам или сайт-путеводитель);
  - объекты карты — то, что чинится кодом.
- **Карта — пять объектов,** по одному на задание (практика — 7 слайдов: хук, пять заданий, вывод; `trebovaniya.md`).
  - Задание N зажигает объект N.
  - Последний объект — работа ученика: появляется с придуманным им названием.
- **Роль ученика** — тот, кто восстанавливает и строит. Герой (Коди) живёт в тексте и голосе, а не в рисунке.
- **Вступление короткое и цепляющее:** одна строка истории на экране и карта; обещание результата («починим шесть систем, а потом сделаем страницу твоей комнаты — код будешь писать сам!»). Названия тегов во вступлении не нужны: язык результата, как в крючке урока (`../../novyy-urok/references/metodika.md`, «Крючок и план»). В 01p история звучала только голосом, а на экране были взрослые слова — это отмечено в плане переделки как недостаток.

## 3. Карточка задания

```markdown
### Задание N · «Название объекта» · ступень лесенки
- Заказ (строка задания, коротко; на телефоне — без потери смысла):
- Материал: свой урок / смесь с уроком K (что именно из него)
- Исходный код (что неизменно, что редактируется); вид редактора: fields / line / block / doc / doc big
- Что пишет ученик сам:
- Условие успеха (прозрачное правило; что из своего текста принимается):
- Фразы проверки (по одной на типичную проблему; «что не так» и следующий шаг):
- Подсказки: 1) направление; 2) место или правило (что подсветить); 3) образец с другим содержимым или указание места
- Дополнительная задача после образца (новое содержимое, тот же принцип):
- Наглядная помощь (видна сразу): схема / «как должно быть» с названиями тегов / скобки вложенности
- Объект карты, который загорается:
- Журнал: kind; ключ store — tN
```

```markdown

## Паспорт
- lessonId: <курс>-<NN>p-<slug>; module; возраст 11–14
- Материал урока, на котором стоит практика (по файлу урока): …
- Смешивание с прошлыми уроками: какие задания смешанные и с каким уроком; что стоит готовой опорой
- Что ученик напишет сам после практики: 1) … 2) … 3) …
- Лесенка письма: какое задание какую ступень закрывает
- Операция и роль ученика; объекты карты (N)
- Артефакт: { type, … }
- Типичные ошибки набора и где их ловит проверка

Карточки (раздел 3).

## Разбор кода
Какие теги знает разбор; правила структуры темы; порядок проверок (запись тега → структура → содержимое).

## Особые правила практики
Что отличается от каркаса 01p и почему («нет», если ничего).
```

## 5. Чек-лист сценария

- [ ] Примерно три задания из четырёх — на умения своего урока; каждое его умение ученик пишет сам хотя бы раз.
- [ ] Прошлые уроки — только как опора, 1–2 задания-смеси и финал; нет целых заданий на повторение старого.
- [ ] Ничего из будущих уроков.
- [ ] Есть все ступени лесенки; последнее задание — своё с нуля, и это артефакт.
- [ ] Основной способ решения — набор текста; выбор и перетаскивание — только как разминка.
- [ ] У каждого задания прозрачное условие успеха; условие для своего текста видно (счётчик).
- [ ] Фразы проверки называют одну проблему и следующий шаг, говорят о правилах учебного документа.
- [ ] Три ступени подсказок под каждое задание; образец третьей ступени — с другим содержимым.
- [ ] Дополнительная задача после образца есть и небольшая.
- [ ] Наглядная помощь видна сразу, подписана названиями тегов, легенда значками.
- [ ] Не однообразно: задания чередуют вид работы, а не только «печатай и Проверить» семь раз подряд.
- [ ] Операция своя, карта показывает продвижение, финал — объект с названием ученика.
- [ ] Строки задания короткие; на телефоне при открытой клавиатуре видны задание, поле и «Проверить».

## 6. Анти-примеры из прежней практики 01p (до переделки 22.10.2026; план переделки)

| Было | Что не так | Как правильно |
|---|---|---|
| Вступление: история только голосом, на экране взрослые слова | Без звука непонятно, зачем всё | Строка «Коди нашёл базу роботов. Почини 6 систем и сделай свою комнату» |
| Т2: «приветствие роботам» со скрытым условием «от 3 слов» | Два дела и невидимое условие | Условие в задании и счётчик «слов 2/3» |
| Т3: набрать `<title>…</title>` с нуля сразу | Перегружено; при клавиатуре прячется название | Шаги: имя между готовыми тегами → закрывающий тег → вся строка; название видно при клавиатуре |
| Т4: «body» есть только в голосе | Без звука неясно, что писать | Написать в задании; схему «открывающий · сообщение · закрывающий» показывать сразу |
| Т5: переставить два текста местами перепечаткой | Тяжело на телефоне | Постановка заказчика прямо требует править самому, без кнопки «Поменять местами». Облегчать короткими текстами и видимой карточкой «как должно быть», а не механикой обмена (предложение из плана переделки отклонено как противоречащее постановке) |
| Т6: дописать `</head>` и `</body>` в многострочном поле | Найти место и вставить дважды — тяжело на телефоне | «Нажми строку, где кончается пунктир» → появляется пустая строка → вписать тег; поставить раньше Т3 |
| Т7: весь документ по чертежу одним заходом | Тяжело для слабого ученика | Три шага с отдельной проверкой: html → head с title → body |
| Семь раз подряд «печатай и Проверить» | Однообразно | Менять вид письма (поле в строке → строка → блок → правка → с нуля) и добавлять короткие шаги на касание, где они помогают найти место (нажать строку, где кончается пунктир), но решение — всё равно набором |

Правки заказчика к 01p, которые уже внесены и действуют для всех практик, — в `trebovaniya.md`:
- без кнопки «Показать отсеки»;
- без кнопки «Чертёж»;
- легенда значками;
- `title` и `body` в подписях;
- подсказка после второй неудачи;
- шапка без Коди.
