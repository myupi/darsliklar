# Каркас практики (шаг Г) — по образцу 01p «Пять вкладок Коди» (облик «Редактор»)

Образец кода — исходник `tools/amaliyot1/` (04.11.2026, с нуля в облике эталона урока 1 «Редактор»; прежние бумажные практики и их исходники удалены заказчиком в тот же день). Собранный файл — `lessons/html/01p-struktura-dokumenta.jsx`, сценарий — `docs/scenarij-01p-struktura-dokumenta.md`, автопроверка — `tools/qa/lesson-team/scenarios/html-01p-struktura-dokumenta.qa.mjs`. Новая практика начинается с копии исходника:

```bash
node .claude/skills/praktika/scripts/shablon.mjs tools/<папка>
```

Скрипт копирует `build.mjs`, `a1.src.jsx`, `a1-screens.jsx`, `a1.css` под именами `aN.*` (N — номер из имени папки), правит пути сборки и файл практики. Дальше: общее не трогать, под тему — переписать, собрать своим `build.mjs`.

**Практика к уроку 2 и дальше** — удобнее копировать 02p «Газета Коди» (`tools/amaliyot2/`, 04.11.2026): `node .claude/skills/praktika/scripts/shablon.mjs tools/<папка> tools/amaliyot2` (имена `a2` в коде заменить на свой номер). В ней уже есть то, чего нет в 01p: разбор `b` и `i` внутри текста (`a2Group`: один кусок текста, закрытие внутри блока, пустой тег), честная страница из блоков как в уроке 2 (`a2Page` → `A2Doc`: заголовки `h1`–`h6`, абзацы, жирный и наклонный, незакрытый заголовок или `b` расползается; страница всегда помещается в окно — `useA2Fit`), проверка по плану для части `body` (`a2Plan`: лишние `html` / `head` / `body`, уровень заголовка, «один абзац»), своя статья (`a2OwnCheck`), код статьи строками и артефакт (`a2Lines`). На телефоне окно браузера выше (16 : 7,5; на высоком — 16 : 9,5), символы и «Проверить» — одним рядом.

## Из чего собирается практика

```
build.mjs        naborRedaktor(gen) — облик эталона в gen/, потом sobrat.mjs
aN.src.jsx       шапка · /*@CANON@*/ · META · UI · TABS (объекты карты) · XTRA · FB · C
  /*@L2_HELPERS@*/                     помощники урока 2: голос, InlineInput, useRec, KeyRow …
  /*@FILE:gen/b16-chrome.jsx@*/        рамка StageB: шапка и низ CoddyCamp, панели «Barakalla!» / ошибки / подсказки
  /*@FILE:gen/p17-skin.jsx@*/          Sheet (стол без бумаги), герой урока 1
  /*@FILE:gen/kollazh-*.jsx@*/         набор урока 1: KzAsk, KzCode, PaperBrowser (Chrome), переход-глитч
  /*@FILE:aN-screens.jsx@*/            разбор кода, редактор, браузер-карта, ход задания, экраны, корень
  LESSON_CSS = CANON_SCREEN_CSS + L2_CSS + kollazh.css + b16.css + p17.css + r28.css + aN.css
```

- Набор облика **подключается, а не копируется** (`naborRedaktor`); `gen/` — в `.gitignore`.
- Набор ждёт в `UI` ключи `up`, `down`, `mySite`, `hello`, `play`, `ready`.
- Экран практики — `StageB` (как в уроках): строка задания — `KzAsk`; что не так — `KzAsk hint=… err` (красная панель), ступень подсказки — `hint` без `err` (жёлтая), решено — `done` (зелёная «Barakalla!» с текстом `KzAsk`). Своих заметок под работой нет.
- Коди — `VoiceDot` в шапке `StageB`; на ноутбуке — кружок в углу, как в уроках. Облака с текстом нет.
- Кнопки «Повторить» в шапке облика нет (как в уроках); `SCREEN_RESET` остаётся для платформы.

## Конфиг задания (`cfgTn(pick, store)`)

```js
{
  id: 't3', num: 3, kind: 'write-block', C: C.t3,   // ключ стора; номер = вкладка карты; тип для журнала
  init: () => ({ code: '  ' }),                     // состояние: { v } — поле в строке, { code } — редактор, { at, code } — найти строку
  check: (st) => a1Plan(st.code, A1_BODY, { textOut: true }),   // { ok, msg, result }
  view: (st, x) => ({                               // x: set, inRef, lv, led, solved, check, t, pick
    title, text,                                    // что на открытой вкладке и в окне (честно, по a1Page)
    editor: <A1Editor … />, aid: <A1Slots … />,     // редактор и помощь
    ask, pageHl, tabHl, big, keys, syms             // смена строки задания по ходу, подсветка, большой редактор, ряд кнопок
  }),
  sample: (pick) => ['<body>', '  …', '</body>'],   // образец третьей ступени — другое содержимое
  onSolved: (r) => …,                               // своя страница — в стор (myTitle, myText)
  drill: { init, check, view }                      // дополнительная задача после образца (у своей работы — нет)
}
```

**Ход задания** (`useA1Task`, общий):
- **Неудачная проверка** → красная панель с причиной и реплика. **Вторая неудача подряд** → к причине сразу добавляется следующая ступень подсказки.
- **Лампочка** (и бездействие — пульс рамки) → следующая ступень, жёлтая панель; на третьей под редактором — образец.
- **Решено после третьей ступени** → дополнительная задача (`Ещё разок: …`), «Дальше» — после неё.
- **Стор `tN`:** `st`, `checks`, `fails`, `lv`, `solved`, `done`, `first`, `drill`, `result`. «Назад» и возврат ничего не теряют.
- **Журнал:** `attempts`, `firstTry`, `hintMax`, `drill`.

## Разбор кода под новую тему

1. **`A1_KNOWN`** — теги своего урока и прошлых, что встретятся в заданиях; `a1Near` подскажет похожий («titel» → `<title>`).
2. **`lexA1`** — оставить; для атрибутов (урок 4+) научить токен `open` хранить атрибуты: `{ k: 'open', name, attrs }`.
3. **Планы** — ожидаемые последовательности темы. Порядок проверок: запись тега (`a1Bad`) → лишнее, что уже есть в рамке (`html`, doctype) → план по шагам → текст (≥ 2 букв) → совпадение с заданным словом (`a1Norm`: регистр, кавычки, апострофы не важны).
4. **`a1Page`** — что покажет браузер. Код не исполнять, только текст; спецсимволы (`<`, `&`) — как текст и в превью, и в артефакте (`escHtml`).
5. **Фразы** — в `FB`, одна на проблему, о правилах «нашей страницы»; без «xato», «noto'g'ri»; в звучащих узбекских фразах без тире (движок делает из тире точку).

## Проверка практики (дополнительно к `../novyy-urok/references/proverka.md`)

Автопроверка — по образцу `html-01p-struktura-dokumenta.qa.mjs`: шаги выполняются в странице (помощники — прямо в шаге); слова задания берутся из строки задания (`«…»` / `“…”`), чтобы основной путь шёл на трёх языках. Поле — `.a1-ta` (редактор) или `.kz-gap textarea` (поле в строке); `inputScreens` — номера экранов с вводом с единицы.

- [ ] **Каждое задание:** верное решение; типичные ошибки — своя фраза в красной панели; вторая неудача подряд — с подсказкой; три лампочки — образец; после него — дополнительная задача.
- [ ] **Карта:** вкладка загорается; на выводе горят все.
- [ ] **«Назад»** на решённое задание: код и карта на месте.
- [ ] **Кнопки символов** вставляют в место курсора и не закрывают клавиатуру.
- [ ] **Открытая клавиатура** (`is-kbd`, 360×640): от браузера — полоса вкладок с живым названием, видны задание, поле и «Проверить».
- [ ] **Раскладка:** полный прогон (5 размеров, 3 языка) и отдельный поиск наложений на 360×640, 390×844, 768×1024 — нижний ряд кнопок не уходит под нижнюю панель.
- [ ] **Безопасность:** `<b>`, `&` в своём тексте — как текст и в превью, и в артефакте.
- [ ] **Финал:** «Работа готова», `onFinished` один раз, артефакт в payload.
