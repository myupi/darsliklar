# Новый урок или практика

Работать по-русски. Цель заказчика: ученик минимально затрудняется, максимально понимает тему, ему не скучно, интерактивность не теряется. Число экранов не ограничено.

## 0. Прочитать перед началом (обязательно)

1. `docs/brif-uroka.md` — бриф v2 целиком: качество урока, контракт, анатомия экрана, Коди, механики, практика, тон, запреты, чек-лист, шаблон сценария.
2. `lessons/<курс>/_course.js` — строка урока: номер, slug, тема, темы-теги; соседние уроки — что ученик уже знает.
3. Эталоны курса HTML:
   - урок 2 `lessons/html/02-zagolovki-i-tekst.jsx` — главный образец механик по правилам качества (экраны 6–17);
   - урок 1 `lessons/html/01-struktura-dokumenta.jsx` — тур по кнопкам, первый урок курса;
   - практика `lessons/html/01p-struktura-dokumenta.jsx` — каркас без Коди (`PStage`), подсказка после неудач, большой редактор.
4. `docs/plan-peredelki.md` — что ещё не переделано и открытые вопросы.

## 1. Сценарий — и стоп до утверждения

Заполнить шаблон из конца брифа и показать заказчику. Код не писать, пока сценарий не утверждён. В сценарии:

- каждая новая тема — тройка экранов «показать → повторить → сделать самому»;
- у каждого экрана одно действие, конкретная формулировка задания, однозначный ответ, что видно сразу;
- реплики Коди на трёх языках (`L3(uz, ru, en)`), обращение UZ «Siz», RU «ты» без рода;
- в репликах нет имени ученика, символов `% / ² + = ×`, слов «ошибка», «неправильно», «xato», «noto‘g‘ri»;
- тесные экраны (код + браузер + кнопки) сразу помечать `voiceTop`.

## 2. Файл урока

- Путь: урок `lessons/<курс>/<NN>-<slug>.jsx`, практика `lessons/<курс>/<NN>p-<slug>.jsx`.
- Сверху — канон дословно: скопировать шапку и блок канона из эталона того же курса (канон между шапкой урока и строкой `const CANON_SCREEN_CSS = …`), затем пометка `// ==============================  У Р О К  ==`.
- Общие помощники курса (`Tag`, `Src`, `Page`, `MiniBrowser`, `InlineInput`, `KeyRow`, `WordLine`, `Stairs`, `LadderNote`, `SpokenTags`, `SPOKEN`, `heroLines` и т. п.) брать из урока 2, а не писать заново.
- Порядок слоёв, `META`, `C`, `SCREENS`, `SCREEN_RESET`, корень — как в брифе («Архитектура файла») и в уроке 2. В корне первым делом `setLmsVoice(voiceGender)`.
- Тексты только в `C` / `UI`. Реплики — ключами из `SPOKEN` (иначе не прогреются). Для строк с «+ h2» на экране — неразрывный пробел и отдельное поле `hint` для голоса.
- Только `react` в импортах. Прогресс в памяти. `onFinished` ровно один раз.
- Практика: Коди не рисуется (`PStage` из эталона), одна лампочка-подсказка, после второй неудачной проверки подряд подсказка приходит сама.

## 3. Канон и Коди — только через сборку

Канон внутри урока не правится. Нужна правка канона или рисунка Коди:

1. править `tools/build-canon.mjs` (точечные замены с понятным комментарием) или `canon/html/*.part.jsx` (Коди: `hero-head.part.jsx` — палитра, `hero-tail.part.jsx` — рисунок и `KODI_CSS`);
2. `npm run canon` — собрать канон, перенести во все уроки курса, проверить совпадение.

Правило Коди: руки вращаются вокруг плечевого шарнира (точка задана координатами в `KODI_CSS`), из позы берётся только поворот руки. Позы — `POSE_SET` в каноне; таблица «когда какую» — в брифе.

## 4. Проверка (до того, как сказать «готово»)

1. `npm run canon:check` — канон в уроках совпадает.
2. `npx vite build --outDir <scratchpad>/dist --emptyOutDir` — собирается.
3. Просмотрщик: `preview_start` с именем `darsliklar`; урок `http://localhost:5173/?lesson=<курс>%2F%23<n>&voice=fast`; экран отдельно `/player.html?file=<курс>/<файл без .jsx>&lang=ru&voice=fast&start=<N>`. Журнал без ошибок, у реплик маркер языка, `onFinished` один раз.
4. Раскладка — в браузерной панели (`javascript_tool`):
   ```js
   const m = await import('/tools/layout-sweep.js');
   m.sweepBg({ lessons: [{ file: 'html/03-spiski', screens: 18 }] });   // фоном
   // через минуту: m.result()  → { runs, problems }
   // запас высоты для решения о voiceTop: m.sweep({ lessons, langs: ['uz'], sizes: [[360, 640]], slack: true })
   ```
   Проблем быть не должно. Запас меньше ~60 px на 360×640 — поставить экрану `voiceTop`.
5. Пройти каждый экран на телефоне (375×740) до конца, включая неверные ответы и все шаги: подсказка встаёт на место задания, экран не вылезает, ясно, что делать. Отдельно — открытая клавиатура (`is-kbd`, `--vvh: 330px`).
6. Отчёт заказчику по-русски: что сделано, что проверено, что не проверено. Скриншоты ключевых экранов.

## 5. Гит

Коммитить и пушить в `main` только когда заказчик попросит («запушь»). Коммиты по смыслу (правила / канон / уроки), сообщения по-русски, в конце строка соавторства из системного напоминания.
