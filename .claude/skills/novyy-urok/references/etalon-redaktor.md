## 1. Что обязательно, что под тему

**Брать в каждый урок:**
- облик «Редактор» (раздел 2), шапку и низ CoddyCamp (раздел 3), переход-глитч со звуком (раздел 5) — через `naborRedaktor`, а не копией;

**Придумывать под тему:** образ темы (герой урока 1 — подросток в худи, голова — head, тело — body — решение урока 1), сюжет, тексты, игры, число экранов.

## 7. Как собрать новый урок в облике эталона

Свой исходник `tools/<slug>/` и короткий `build.mjs`: сначала набор облика в свою папку `gen`, потом `sobrat.mjs`.

```js
// tools/<slug>/build.mjs
import { dirname, join, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';
import { execFileSync } from 'node:child_process';
import { naborRedaktor } from '../redaktor28/nabor.mjs';
const here = dirname(fileURLToPath(import.meta.url));
const root = resolve(here, '../..');
naborRedaktor(join(here, 'gen'));   // папку gen/ — в .gitignore
execFileSync('node', [join(root, '.claude/skills/novyy-urok/scripts/sobrat.mjs'),
  join(here, '<slug>.src.jsx'), join(root, 'lessons/html/<NN>-<slug>.jsx')], { stdio: 'inherit' });
```

В исходнике — порядок включений как у урока 1 (`tools/redaktor28/gen/r28.src.jsx` после сборки):

```js
/*@L2_HELPERS@*/
/*@FILE:gen/b16-chrome.jsx@*/
/*@FILE:gen/p17-skin.jsx@*/
/*@FILE:gen/kollazh-paper-data.jsx@*/
/*@FILE:gen/kollazh-paper.jsx@*/
/*@FILE:gen/kollazh-kit.jsx@*/
/*@FILE:gen/kollazh-trans.jsx@*/
/*@FILE:<slug>-screens.jsx@*/
const LESSON_CSS = CANON_SCREEN_CSS + `
/*@L2_CSS@*/
/*@FILE:gen/kollazh.css@*/
/*@FILE:gen/b16.css@*/
/*@FILE:gen/p17.css@*/
/*@FILE:gen/r28.css@*/
/*@FILE:<slug>.css@*/
`;
```

- `META`, `L3`, `UI`, `C`, `SPOKEN` — в исходнике выше включений, как в `tools/kollazh/kollazh.src.jsx`; набор ждёт в `UI` ключи `up`, `down`, `mySite`, `hello`, `play`, `ready`.
- Экраны — по образцу `tools/bdizayn16/b16-screens.jsx`: `StageB`, `useVoice`, `useCanAnswer`, `useAdvanceGate`, `useIdleLed`, `useRec`, `KzAsk` (с `err`), `navOf`, `useKzDemo` на объяснениях; корень — `useKzTransition(cur.id + ':' + R.runN)` и `next: go(R.next, 1), prev: R.i > 0 ? go(R.prev, -1) : null`.
