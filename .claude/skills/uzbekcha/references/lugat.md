# Словарь и написание

## Термины курса HTML

| Понятие | Узбекский | Примечание |
|---|---|---|
| тег | **teg** | в озвучке звучит английское «tag» (движок, `kzTagWord`): «tegi» → «tag-i». В тексте пишем «teg». |
| открывающий / закрывающий тег | **ochuvchi / yopuvchi teg** | «yopuvchi html tegi», «ochuvchi head tegi» |
| угловая скобка | **burchakli qavs** | левая — «chap burchakli qavs», правая — «o‘ng burchakli qavs»; коротко — «qavs» |
| косая черта | **qiya chiziq** | «qiya chiziqli yopuvchi teg», «qiya chiziqsiz ochuvchi teg» |
| вкладка браузера | **yorliq** | только вкладка. Кнопка в игре — «Yorliq». Урок 1 курса по текстам заказчика 28.10.2026 говорит «brauzer varag‘i», кнопка «Varaq» — его не переписывать. В одном уроке — одно слово. |
| окно браузера | **oyna**, **brauzer oynasi** | «Oyna» — кнопка в игре |
| название страницы (title) | **sahifaning nomi**, **sahifa nomi** | не «ism». h1 — «asosiy sarlavha», не «nom» |
| заголовок / абзац | **sarlavha / xatboshi** | урок 2 |
| жирный / курсив | **qalin / qiya** | урок 2 |
| список | **ro‘yxat** | маркированный, нумерованный — по уроку 3 |
| ссылка | **havola** | урок 4 |
| атрибут | **atribut** | «src atributi», «alt atributiga» |
| картинка | **rasm** | урок 5 |
| код, строка кода | **kod, qator** | «kod qatori», «bo‘sh qator», полоска в игре — «qatorcha» |
| браузер | **brauzer** | |
| веб-страница | **veb-sahifa**, **sahifa** | |
| программист | **veb-dasturchi**, **dasturchi** | не «veb-usta» |
| кнопка помощи | **Yordam** | канон |

Английские слова тегов и атрибутов (`html`, `head`, `title`, `body`, `src`, `alt`, `href`) пишутся латиницей как есть и звучат по-английски во всех языках.

## Английское слово + аффикс

Аффикс **не отделяется пробелом** и **не клеится** к английскому слову (заказчик, v2, п. 11). Он переходит к узбекскому слову рядом:

| Нельзя | Можно |
|---|---|
| title ni, titleni | **title tegini** |
| body dagi, bodydagi | **body tegidagi**, **body ichidagi** |
| head dan | **head tegidan**, **head qismidan** |
| html ga | **html tegiga**, **html ichiga** |
| src da | **src atributida** |
| alt ni | **alt atributini** |

Без аффикса английское слово стоит свободно: «title head ichida yashaydi», «Oldin head keladi, keyin body.»

## Глаголы действий ученика (на «Siz»)

| Действие | Как пишем |
|---|---|
| нажать | **bosing**, «bosib ko‘ring», «ustiga bir bosing» |
| написать | **yozing**, «yozing-da, … bosing» |
| перетащить | **«ushlab, joyiga olib boring»**, «… olib boring». Урок 1 курса — «suring». Не «torting». |
| выбрать | **tanlang** |
| посмотреть | **qarang**, «bir qarang-chi», «kuzatib turing» |
| сравнить | **solishtirib ko‘ring** |
| проверить себя | «o‘zingizni sinab ko‘ring» |
| сдвинуть стрелками | «o‘qchalar (strelkalar) bilan tepaga yoki pastga suring» |

## Кнопки и подписи

«Tekshirish» (Проверить), «Tayyor» (Готово), «Davom etish» (Дальше), «Orqaga» (Назад), «Yordam» (Подсказка), «Aylantirish», «Qayta urinish», «Tushunarli». В реплике кнопка — в «ёлочках» с аффиксом снаружи: «Tekshirish»ni bosing, «Tayyor»ni bosing.

## Написание букв

- **o‘ g‘** — знак ‘ (U+2018): «ko‘ryapsizmi», «to‘g‘ri», «o‘rtasida». Не `o'`, `oʻ`, `o``.
- **Твёрдый знак-апостроф** — ’ (U+2019): «ma’lumot», «a’lo», «ya’ni».
- **Кавычки** — «ёлочки»: «Salom», «Tekshirish». Внутри — „…“ не нужно.
- Движок сам меняет ‘ ’ на `'` в тексте для сервиса озвучки — на экране оставляем ‘ ’.

## Запретное и нежелательное

- **«xato», «noto‘g‘ri»** — никогда про ответ ученика. Вместо них зачины из `qoliplar.md` («Oz qoldi!», «Hechqisi yo‘q!», «Unday emas:»…). Про сломанную страницу или ошибку Коди — допустимо («nimadir buzilib qolibdi»).
- **«sen» и повеление без -ing** («bos», «yoz») — только «Siz».
- **«Klass!»** — «Ajoyib!»; **«veb-usta»** — «veb-dasturchi»; **«varaqcha»** — не используется.
- **Имя ученика** в репликах не звучит.
