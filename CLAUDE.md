# Darsliklar

Просмотрщик интерактивных JSX-уроков для детей (Vite + React 18). Уроки — самодостаточные файлы в `lessons/`, просмотрщик открывает их в iframe с эмуляцией платформы `@lesson/runtime`. Подробности для пользователя — в README.md.

## Источник правил

- `docs/brif-uroka.md` — бриф: контракт с платформой, анатомия экрана, механики, тон, чек-лист приёмки. Новый урок пишется строго по нему.
- `canon/html/canon-v1.jsx` — канон курса HTML. Каждый урок курса копирует его ДОСЛОВНО сверху, урок — ниже пометки «УРОК». Внутри урока канон не правится.
  - Канон собран скриптом `node tools/build-canon.mjs` из эталонов в `lessons/_reference` (канон Курса 0 + переходник озвучки Кибербеза + герой Коди из `canon/html/*.part.jsx`). Места склейки помечены «СКЛЕЙКА».
  - Проверка совпадения: `node tools/check-canon.mjs` (для другого курса — `node tools/check-canon.mjs <курс>`).

## Где лежат уроки

- Урок: `lessons/<курс>/<NN>-<slug>.jsx`. `NN` — двузначный номер из плана курса; по нему файл привязывается к плану. `slug` брать из `_course.js`.
- План курса: `lessons/<курс>/_course.js` (title, subtitle, short, color, order, lessons[{ n, slug, title, topics, final? }]).
- Новая тема → строка в `_course.js`. Новый курс → новая папка с `_course.js`.
- `lessons/_reference/` — эталоны других курсов. Только читать, не править.

## Правила для файла урока

- Один файл = один урок, `export default` корневой компонент.
- Пропсы: `{ studentName, lang, onFinished }`; `onFinished(payload)` — ровно один раз.
- Импорты: только `react` и `@lesson/runtime` (`useAudio`, `useSfx`, `useAssets`) — так требует бриф.
- API эмуляции описан в шапке `src/runtime/index.js`. Если урок не работает в просмотрщике, чинится урок, а не `src/runtime`. В эмуляцию добавляется только то, что реально умеет платформа.

## Проверка после создания урока

1. Запуск: `preview_start` с именем `darsliklar` (или `npm run dev`, порт 5173).
2. Открыть урок: `http://localhost:5173/?lesson=<курс>%2F%23<n>&voice=fast` («Быстро» — тихие короткие паузы для прогона).
3. Отдельный экран без просмотрщика: `/player.html?file=<курс>/<файл без .jsx>&lang=ru&voice=fast&start=<N>`.
4. Журнал справа: без ошибок, у реплик есть маркер языка, `onFinished` вызван ровно один раз.
5. Нет переполнения `.stage-content` на 360×640 и 1440×900 (в том числе при открытой подсказке и с классом `is-kbd` при `--vvh: 330px` — так выглядит открытая клавиатура телефона).
