## Замысел

Сайт кружка разложен по сетке: контейнер, ряд, колонки с блоками `card card-body` (как в уроке 6). При обновлении слова сетки
пропали — блоки во всю ширину. Окно страницы своей ширины: телефон 360, планшет 768, ноутбук 1024 — `@media` срабатывают честно.

Умения урока, которые ученик пишет сам: `col-N` — доля из 12; `row` — колонки в ряд; `container` — посередине; адаптивное
`md:col-4` (двоеточие; `col-md-4` — имя версии 5); пример Grid с сайта копируется и настраивается. Ошибки урока: `rows`,
`col-md-6`, `md-col-4`, `col-13`, `container-fluid`, `d-flex` вместо `row`. Опора — уроки 4–5 (flex, card).
