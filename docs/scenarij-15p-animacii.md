**Замысел.** На космическом сайте Коди ракета, звёзды и планеты двигались сами; после обновления CSS стёрся — всё замерло. Ученик оживляет пять страниц: повторы, кадр в процентах, правило `animation` целиком, поломки, своя анимация. Проверка — по вычисленным `animation-name`, `animation-duration`, `animation-iteration-count`, `animation-timing-function` и по кадрам `@keyframes` (берётся последний план с этим именем — как у браузера; кадр «50» без % браузер выбрасывает). Многострочные планы — готовые строки над полем или в самом поле.
