**Замысел.** На сайте книжного клуба Коди стёрся CSS: шрифт стал обычным, заголовок съехал к краю, под ссылкой снова черта. Ученик возвращает пяти страницам вид текста — размер, выравнивание, шрифт, жирность, черту — и чинит две поломки урока.

| # | Слайд | Что делает ученик | Ответ | Поломки и ветки (своя причина) |
|---|---|---|---|---|
| 1 | крючок | «Обновить» — стили пропали, вкладки гаснут | — | — |
| 2 | т1 Новинки | заменить число в готовом правиле: заголовок 36 пикселей | `h1 { font-size: 36px; }` | число без px (причина каркаса); другой размер; доп.: абзацы `18px` |
| 3 | т2 Стихи | вписать свойство и значение в правило `body { }`: весь стих по центру (готово: цвет h1) | `text-align: center;` | по центру только часть страницы — нужен body; `middle`; доп.: подпись `.author` вправо — `right` |
| 4 | т3 Книги про код | правило целиком: шрифт всей страницы «как в редакторе кода» | `body { font-family: monospace; }` | шрифт не моноширинный; только у части страницы; доп.: ссылка без черты — `a { text-decoration: none; }` |
| 5 | т4 Встреча | найти и починить две поломки урока (готово: фон body) | `font-size: 40px` (было `40` — загадка урока), `text-align: center` (было `centre`) | число без px; значение, которого браузер не знает; доп.: `font-weight: bolt` → `bold` |
| 6 | т5 Моя книга | своя страница: размер h1, шрифт, выравнивание (условия видны и загораются) | любые значения | нет font-size у h1 / font-family / text-align; заголовок мельче текста |
| 7 | вывод | все вкладки горят, своя страница и её код, умения, дальше — «Размеры элементов» | — | — |

«Courier New» без кавычек в поломки не взят: браузер такое имя принимает (`CSS.supports('font-family', 'Courier New, monospace')` — true), честный браузер его не «сломает».

Помощь на каждом задании: 1 — направление, 2 — правило словами (свойство, значение), 3 — образец под кодом с другим содержимым; со второй неудачи подряд ступень открывается сама; после образца — дополнительная задача.
