## Паспорт

- lessonId `html-01p-struktura-dokumenta`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона.
- Материал урока 1 (по файлу урока): тег — слово в угловых скобках, браузер его не показывает, а читает; открывающий и закрывающий (с косой чертой); `title` внутри `head` — название на вкладке; `body` — всё, что видно в окне; порядок `<!DOCTYPE html>`, `html`, `head` с `title`, `body`; пропущенный `</title>` уносит текст страницы на вкладку.
- Смешивания с прошлыми уроками нет (урок первый). Будущего нет: ни `h1`, ни `p`, ни атрибутов.
- Что ученик напишет сам: 1) название между тегами `title`; 2) строку `<title>…</title>` целиком; 3) блок `body` с текстом; 4) найдёт и починит незакрытый `title`; 5) свою страницу внутри готовой рамки `html`: `head` с `title` и `body`.
- Лесенка письма: т1 слово между тегами (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своя страница по схеме (большой редактор).
- Операция: сбой стёр код пяти любимых страниц Коди — вкладки браузера погасли. Ученик чинит их по одной, пятая — его своя страница с его названием. **Карта — сами вкладки браузера:** погасшая — серый значок, починенная — цветной значок и название, текущая — открыта. Так карта повторяет главную мысль урока: название из `title` видно на вкладке.
- Артефакт: `{ type: 'html-page', title, text, html }` — своя страница из т5.
- Типичные ошибки набора: нет `/` в закрывающем (`<title>` вместо `</title>`), обратная черта `\`, нет `<` или `>`, опечатка в имени (`titel`), текст вне тегов, не закрыт `title` / `body` / `head`, `body` до `head`, `title` вне `head`. Проверка называет одну, самую полезную проблему.

### Общий ход задания

- Строка задания — `KzAsk`; «Проверить» — в ряду кнопок `< / >` под редактором. Во время набора замечаний нет, браузер обновляется сразу и честно.
- Первая неудачная проверка — красная панель «что не так». Со второй неудачи подряд к ней сразу добавляется следующая ступень подсказки.
- Лампочка — ступени 1 → 2 → 3 (жёлтая панель). На третьей под редактором виден образец с другим содержимым.
- Решено после третьей ступени — короткая дополнительная задача на тот же принцип (т1–т4), «Дальше» после неё.
- Решено — зелёная панель «Barakalla!», вкладка загорается.
- «Назад» сохраняет код, ступень и решённость; «Повторить» стирает только текущее задание (своё название из т5 — тоже, если повторяют т5).
- Журнал: `attempts` (проверки), `firstTry`, `hintMax`, `drill`.

### Т1 · «Musiqa» · поле в строке
- Заказ: «title ichiga «Musiqa» deb yozing».
- Код: полный документ, поле — между `<title>` и `</title>`; в окне — «Eng yaxshi qo'shiqlar».
- Успех: текст поля = «Musiqa» (регистр, пробелы, кавычки не важны).
- Фразы: пусто; есть угловые скобки — «faqat so'z»; другое слово — «на вкладке X, нужно Musiqa».
- Подсказки: 1) название страницы живёт в `title`; 2) поле между `<title>` и `</title>` (поле мигает); 3) образец `<title>Kitoblar</title>`.
- Дополнительная задача: название «Sport».

### Т2 · «O'yinlar» · строка
- Заказ: «head ichiga title qatorini yozing: nomi «O'yinlar»».
- Код: `<!DOCTYPE html>`, `<html>`, `<head>` · [строка] · `</head>`, `<body>`, текст, `</body>`, `</html>`.
- Помощь видна сразу: три места строки — `<title>` · nom · `</title>`.
- Успех: `<title>O'yinlar</title>`.
- Фразы: нет открывающего; другой тег вместо `title`; нет косой черты в закрывающем; нет закрывающего (вкладка честно показывает хвост документа); пустое название; другое название; текст после `</title>`; плохая запись тега (нет `<`/`>`, `\`, опечатка).
- Подсказки: 1) название страницы — в `title`, `title` — в `head`; 2) три части: открывающий, название, закрывающий с «/»; 3) образец `<title>Sport</title>`.
- Дополнительная задача: `<title>Kitoblar</title>`.

### Т3 · «Ob-havo» · блок
- Заказ: «</head> dan keyin body qismini yozing, ichida — «Bugun quyoshli»».
- Код: документ до `</head>` · [блок] · `</html>`.
- Помощь: три строки — `<body>` · matn · `</body>`.
- Успех: `<body>`, текст (≥ 2 букв), `</body>`.
- Фразы: текст без `body` («окно покажет, но по нашему правилу текст — внутри body»); другой тег; нет текста; нет косой черты; не закрыт `body`; текст после `</body>`.
- Подсказки: 1) всё, что видно в окне, — в `body`; 2) три строки; 3) образец с «Salom!».
- Дополнительная задача: блок `body` с «Ertaga yomg'ir».

### Т4 · «Kino» · найти и исправить
- Заказ: «Matn varaqqa chiqib ketdi. Buzilgan qatorni bosing» → после верного нажатия «Shu qatorni tuzating».
- Код: полный документ, в строке 4 `<title>Kino` без `</title>`. Браузер честно: на вкладке «Kino </head> <body> Yangi multfilmlar …», окно пустое.
- Неверная строка — своя причина, почему она в порядке, и куда смотреть.
- Верная — строка становится полем с её текстом; дописать `</title>`. Название остаётся «Kino».
- Подсказки: 1) какой тег не закрыл свою часть; 2) строка с названием (мигает); 3) образец `<title>Sport</title>`.
- Дополнительная задача: та же поломка на странице «Sport».

### Т5 · своя вкладка · своё по схеме
- Заказ: «html ichida o'z sahifangizni yozing: head, title, body».
- Код: `<!DOCTYPE html>`, `<html>` · [большой редактор] · `</html>`.
- Помощь (схема, видна сразу): `html` ✓ → `head` → `title` (sahifa nomi), `body` (oynadagi matn).
- Успех: `head` с `title` (своё название ≥ 2 букв) и `body` (свой текст ≥ 2 букв), всё закрыто, порядок верный.
- Фразы — по первой расхождению с порядком: что ждём и что встретили (title вне head, body до head, не закрыт head/title/body, лишний html или DOCTYPE, текст до тегов, текст после `</body>`).
- Подсказки: 1) по схеме: сначала head, потом body; 2) title — внутри head, каждый открытый тег закрывается; 3) образец всей части с другим содержимым («Sport» / «Bugun futbol»).
- Дополнительной задачи нет: это своя работа.

## Особые правила практики

- Код ученика не исполняется: разбор только находит теги и текст, страница рисуется React как текст.
- Честный браузер: незакрытый `title` уносит весь остальной код на вкладку, окно пустеет; текст без `body` браузер всё равно показывает в окне — проверка говорит, что по правилу нашей страницы он внутри `body`.
- В речи `title`, `head`, `body`, `html` — по-английски; символов в репликах нет.
