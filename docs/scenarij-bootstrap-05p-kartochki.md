# Практика 5 модуля Bootstrap — «Robotlar kartochkalari» («Карточки роботов»)

К уроку 5 «Карточки» (`lessons/bootstrap/05-kartochki.jsx`). Файл — `lessons/bootstrap/05p-kartochki.jsx`, данные — `tools/bsp/p05.jsx`,
сборка — `node tools/bsp/build.mjs 05`, автопроверка — `tools/qa/lesson-team/scenarios/bootstrap-05p-kartochki.qa.mjs`
(`node tools/bsp/mkqa.mjs 05`). Каркас — `tools/bsp` (`README.md`).

## Замысел

Страница роботов кружка — карточки (фото, имя, описание, кнопка); фото — рисунки урока 5 (`robot1–3.jpg`). При обновлении у
тегов пропали слова card — всё рассыпалось. Ученик восстанавливает пять страниц, пятая — своя галерея из двух карточек.

Умения урока, которые ученик пишет сам: `card` (рамка) и `card-body` (отступы внутри; `card-title` и `card-text` — только
имена, в CSS 6.0 правил нет — разбор их знает), `card-img-top`, цвет `card theme-*`; пример карточки с сайта копируется и
настраивается: `src="..."` → свой файл, свои имя, описание и надпись кнопки; ряд карточек — `d-flex gap-*` (урок 4).
Ошибки урока: файл без окончания, `card-success`, `bg-*` вместо `theme-*`.
