## Паспорт

- **Ученик:** 11–14 лет, проходит сам, чаще с телефона. Уже знает правило, селекторы (в том числе `.class`), цвета, фон, текст, размеры, Box Model, карточки, `display` (уроки 1–9).
- **После урока ученик сможет:**
  1. поставить детей в ряд: `display: flex` пишут коробке-родителю, а не детям;
  2. задать направление: `flex-direction` — `row`, `column`, `row-reverse`, `column-reverse`;
  3. показать главную ось (по направлению) и поперечную (поперёк; по ней дети растягиваются);
  4. найти поломку: опечатка (`colum`), `flexbox` вместо `flex`, направление без `display: flex`.
- **Не забегаем:** `justify-content`, `align-items`, `gap`, `flex-wrap` (урок 11), `flex-grow` и `order`.
- **Новые слова (черновые):** `ota quti` (коробка-родитель), `bola` (ребёнок), `javon` (полка), `yo'nalish` (направление), `asosiy o'q` (главная ось), `ko'ndalang o'q` (поперечная ось), `ustun` (столбик), `qator` (ряд).

## Особые правила урока

- **Честный браузер.**
  - Верная ли запись — решает сам Chrome (`CSS.supports`): `colum` и `flexbox` не принимаются.
  - `flex-direction` без `display: flex` честно ничего не делает, стрелок тогда нет.
  - Растяжение детей по поперечной оси — поведение самого браузера (`align-items` по умолчанию), без дополнительного кода.
- **Основа страницы** — тусклая строка `.karta { background-color: lavender; margin: 4px; }`; у меню (w1) — `a { background-color: lavender; }`.
- **Экран s4 на телефоне:** строки HTML крупные (16 px, высота от 40 px), чтобы попасть пальцем.
- В речи названия свойств и значений — по-английски (правка речи в `build.mjs`).
