## 1. Что получится (как у HTML)

- Каждый урок 1–16 → две части = 32 урока, **своё название у каждой** (без «часть/qism»), **сквозные номера 1–33** (урок 17 → 33). Файлы `lessons/css/<NN>q1-<slug>.jsx`, `<NN>q2-<slug>.jsx`.

- Тесты → **5 на каждую часть**: 80 → 160 (80 новых вопросов; прежние 80 раскладываются по темам частей).
- Порядок в списке: урок ч.1 → практика ч.1 → 5 тестов → урок ч.2 → практика ч.2 → 5 тестов.
- Новые экраны: вывод части 1 (E1: итог, загадка разгадывается здесь, если хватает материала части 1) и крючок части 2 (H2). Загадка урока задаётся в S1 части 1.

## 5. Чему научились на HTML (чтобы не повторять)

- Независимая оценка показала: после деления новые экраны E1 и H2 звучат шаблонно («Endi sirni ochamiz!», «Salom! O'tgan darsda…», «Ketdik!») и 16 из 34 частей HTML остались ниже 85%. **В бриф помощникам CSS с самого начала:** у каждого урока своё начало E1 и свой ход H2, разные концовки; на стыке частей проверять обещания («дальше научимся X» — только если X в следующей части); после удаления разгадки из S15 переписывать начало итога («Bu esa…» без опоры).
- Заменять «часть/qism» в экранах на «урок/практика» сразу, а не после.
- Замер «без прокрутки» для тестов на 360×640: варианты ответов короткие (до ~30 знаков), в вопросе не больше 3 строк кода; помощникам сказать заранее.
- Автопроверку гонять **по очереди**, не параллельно: параллельные прогоны дают ложные падения по таймеру.
