# Сценарий: модуль Bootstrap, урок 1 «Введение в Bootstrap» (19.11.2026)

Файл урока: `lessons/bootstrap/01-vvedenie.jsx`, сборка `node tools/bs1/build.mjs`. Облик «Редактор» (как HTML и CSS),
канон — `canon/bootstrap/canon-v1.jsx` (копия канона CSS). Источник — https://getbootstrap.com/docs/6.0/
(версия `6.0.0-alpha.1`). Решения заказчика — `CLAUDE.md`, «Модуль Bootstrap».

## Что ученик уже знает

HTML (теги, атрибуты, `class` и `id` — урок CSS 2), CSS (правило, селектор `.class`, цвет, фон, отступы, рамки, flex,
адаптивность), модуль «ИИ». Не знает: что такое библиотека CSS, CDN, сайт документации Bootstrap, классы Bootstrap 6.

## Учебные результаты

После урока ученик сможет:
1. объяснить, что Bootstrap — это готовый CSS, который написали другие, а мы только ставим имена его классов;
2. найти на сайте Bootstrap нужную страницу (Install, Components → Alert) по меню слева;
3. скопировать с сайта строку CDN (`<link>` в `head`, `<script>` перед `</body>`) и вставить её на место;
4. скопировать пример компонента и настроить его под себя: свой текст и цвет `theme-*` — словом с сайта.

## Затруднения и где они разобраны

- «Bootstrap надо скачать / установить» — загадка Коди в крючке, разгадка в выводе (это одна строка-ссылка).
- «Достаточно ссылки» или «достаточно class» — опыт x1: нужны оба, по одному страница не одевается.
- Теряются на английском сайте — показы g1 (Google → сайт → Read the docs → Install) и sc (меню → Alert), потом сами t1, t2.
- Путают, где `<link>`, где `<script>` — показ s9, сам t1 (вставить в head, перенести script в конец body).
- Пишут цвет своими словами (`theme-pink`, `yashil`) — w1: Bootstrap знает только свои слова, их берут из Variants.
- Правят скопированную ссылку, берут класс из Bootstrap 5 — t4 «почему не работает».

## Образ и сюжет

Сайт «Robot to'garagi» (кружок роботов), на нём объявление «Robot to'garagi ochildi!». Коди целый вечер писал CSS для
красивого объявления вручную — 12 строк. Bootstrap делает то же одним `class`. Ученик — напарник Коди: учится брать
готовое с сайта Bootstrap и подстраивать под себя. В конце — своё объявление своего цвета.

Компонент урока — **Alert** (`<div class="alert theme-success" role="alert"><p>…</p></div>`, как на сайте 6.0):
кнопки целиком — урок 2. На сайте документации — тот же код, что на getbootstrap.com.

## Особенности реализации

- Страница в окне Chrome — честная: iframe без скриптов, внутри — настоящий `bootstrap.min.css` 6.0.0-alpha.1
  (`tools/bootstrap/vendor/`, хеш совпадает с `integrity` с сайта). Без ссылки CDN страница — голая, со шрифтами
  браузера; со ссылкой — вид Bootstrap. Испорченная ссылка — файла нет, страница голая.
- Скрипт Bootstrap имитируется: кнопка закрытия у объявления (`btn-close`, `data-bs-dismiss="alert"`) работает,
  только когда в коде есть строка `<script>`.
- Сайт документации — похожая на getbootstrap.com страница в окне Chrome (светлая тема): верхняя полоса, меню
  разделов слева (те же разделы и пункты, что в 6.0), страница с примером и кодом с кнопкой «Copy». На телефоне меню —
  отдельным видом, как кнопка «Browse docs» на настоящем сайте.
- Копирование и вставка — нажатиями: значок копирования на сайте → строка «✎ Shu yerga qo'ying» в редакторе (t1, t2).
- Показы g1, s9, sc — «как на видео»: курсор показов (`tools/mysh`) делает в окнах браузера то, что делает человек
  (поиск, «Read the docs», меню, значок копирования, крестик на странице); в редактор строки влетают сами.
- Длинное значение `integrity` в редакторе свёрнуто, как в VS Code (`sha384-B/GM…CrCe`); где ссылка не главная —
  свёрнут и адрес (`…/bootstrap.min.css`).
