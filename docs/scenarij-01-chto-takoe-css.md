## Особые правила урока

- **Честный браузер.** CSS разбирается настоящим мини-разборщиком (`cssParse`): селектор, объявления через `;`, `свойство: значение`. Принимает ли браузер значение — решает сам Chrome (`CSS.supports`), поэтому любой настоящий цвет красит, выдуманный — пропускается. Без `:` объявление пропускается; без `;` между двумя свойствами значение становится неверным и пропускаются оба; неизвестное свойство (`colr`) — пропускается. Стили ложатся на настоящие элементы (body, h1, p), наследование — как в браузере (цвет body красит и заголовок). Фон body заливает всё окно страницы.
- В речи CSS, style, color, background-color и имена цветов — по-английски (правка речи в `build.mjs`).
- Телефон: окно браузера выше (16 : 10, на 360 × 640 — 16 : 8), на s14 — ниже, чтобы «Готово» не наезжал на палитру; с открытой клавиатурой палитра прячется.
