# Практика к уроку 3 · «Походный блокнот» · курс HTML

Новая практика к уроку 3 «Списки» (22.10.2026). Каркас и вид — практики 01p «Бумажная улица» и 02p «Стенгазета», стиль — урок 1 «Бумажная страница». Ровно **семь слайдов**: хук, пять заданий от лёгкого к сложному, вывод. У каждого задания своя механика.

## Паспорт

- **Файл:** `lessons/html/03p-spiski.jsx`, `lessonId: html-03p-pohodnyy-bloknot`, модуль `html-m1-osnovy`, ученики 10–14 лет, проходят сами. В плане курса — `practiceTitle: 'Походный блокнот'`.
- **Исходник:** `tools/praktika-03/`:
  - `p03.src.jsx` — META, тексты на трёх языках;
  - `p03-engine.jsx` — механика 02p со списками:

    - проверка фрагмента со списками (`checkFrag`), счётчик — по строкам с поломкой;
    - карта — тропа с привалами;
    - образец «как должно быть» (`ListTarget`);
  - `p03-screens.jsx` — хук, конфиги заданий, вывод, корень;
  - `p03.css`.
- **Бумажный набор** подключается из `tools/kollazh/`.
- **Сборка:** `node .claude/skills/novyy-urok/scripts/sobrat.mjs tools/praktika-03/p03.src.jsx lessons/html/03p-spiski.jsx`.
- **Автопроверка:** `tools/qa/lesson-team/scenarios/html-03p-spiski.qa.mjs`.
- **Материал урока 3:**
  - `ul` — список с точками, порядок не важен;
  - `ol` — с номерами, порядок важен;
  - `li` — пункт, только внутри `ul` или `ol`;
  - текст без `li` — без точки;
  - `<li>` вместо `</li>` — пустой пункт;
  - пары совпадают.
- **Смешано с прошлыми уроками:**
  - во всех заданиях готовая рамка документа урока 1 (`head` с `title`, `body`) и заголовки `h2` урока 2;
  - в задании 5 ученик сам пишет `h1` урока 2.
- **Что ученик напишет сам:**
  1. новый пункт `li`;
  2. смену `ul` на `ol` в двух тегах;
  3. список `ul` из строки через запятую;
  4. починку сломанных пунктов;
  5. страницу со своим списком с нуля.
- **Операция:** походный блокнот Коди — пять привалов на тропе, у каждого свой список. Дождь (касание в хуке) размыл теги. Ученик восстанавливает четыре списка и пишет свой.
- **Тропа — индикатор продвижения.** Привал ждёт: флажок выцвел и покосился, мини-список размыт. Готов: свой цвет, ровно, галочка. У «Тропы» и «Палатки» на флажке номера, у остальных — точки. Свой список до написания — пунктирный круг, потом на нём название ученика.
- **Артефакт:** `{ type: 'html-page', title, text, items, html }` — страница со своим `h1` и списком.

## Лестница сложности и механики

| # | Механика | Что меняет ученик |

| 1 | Дописать строку в готовый список | Один `<li>компас</li>` |

| 3 | Из текста — в структуру | Строку «шапка, вода, карта» превратить в `ul` с тремя `li` |
| 4 | Поиск поломок со счётчиком | Текст без `li` и `<li>` вместо `</li>` в чужом списке |
| 5 | С нуля по живому списку условий | `h1` и список с тремя пунктами |

**Подсказки** — три ступени по лампочке. Со второй неудачи подряд ступень приходит сама.
- Вторая ступень:
  - в «Палатке» — «Посмотри на строку N», строка подсвечивается;
  - в своём списке — по первому невыполненному условию.
- Третья ступень — образец с другим содержимым:
  - `<li>шапка</li>`;
  - начало и конец `ol`;
  - `ul` «хлеб, сыр»;
  - правильный `ol` бутерброда;
  - страница «Мои книги».
