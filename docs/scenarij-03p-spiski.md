## Паспорт

- lessonId `html-03p-spiski`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона.
- Материал урока 3 (по файлу урока): `ul` — список с точками, порядок не важен; `ol` — список с номерами, номера ставит браузер; `li` — пункт, всегда внутри `ul` или `ol`; без `ul`/`ol` строки склеиваются; текст в списке без `li` — без точки; номер, вписанный руками в `ol`, — второй номер (загадка урока: «1. 1.»).
- Смесь: с уроком 2 — заголовок `h1` над списком (задания 1, 5); своя страница — `h1` и список.
- Что ученик напишет сам: 1) слово в пустом `li`; 2) строку `<li>…</li>` целиком; 3) список `ol` из трёх и больше `li`; 4) найдёт и уберёт номер, вписанный руками; 5) свою страницу: `h1`, потом `ul` или `ol` с тремя и больше `li`.
- Лесенка письма: т1 слово (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своё по схеме (большой редактор).
- Операция: у Коди завтра день рождения, сайт для гостей из пяти страниц. При сохранении теги списков пропали — пункты слиплись в одну строку, вкладки погасли. Ученик чинит страницы по одной, пятая — его список. **Карта — вкладки браузера** (как в 01p и 02p): Menyu, Bezaklar, Tort retsepti, Tayyorgarlik, Mening ro'yxatim.
- Код — часть `body`, как в уроках 2–3.
- Артефакт: `{ type: 'html-page', title, heading, items, html }` — своя страница из т5 (`html` — весь документ, тексты через `escHtml`).
- Типичные ошибки набора: текст без `li` («нет точки или номера»), `li` без списка, `ul` вместо `ol` для шагов, номера руками в `ol`, меньше трёх пунктов, незакрытый `li` / `ol` / `ul`, `<ol>…</ul>`, лишний `<ul>` там, где список уже есть, страница без `h1`, плохая запись тега.

## Задания

- **Т1 · Menyu.**
  - Подсказки: 1) найди пустой пункт; 2) пиши между тегами `li`; 3) образец `<li>Salat</li>`.
  - Дополнительная задача: «Muzqaymoq».
- **Т2 · Bezaklar.**
  - Помощь: `<li>` · so'z · `</li>`.
  - Фразы: текст без `li`; лишний `<ul>` («список уже есть»); нет `/`; другое слово.
  - Подсказки: 1) `ul` уже есть, пункт — в `li`; 2) три части; 3) образец `<li>Gullar</li>`.
  - Дополнительная задача: «Konfetti».
- **Т3 · Tort retsepti.**
  - Помощь: `<ol>` · `<li>` qadam `</li>` × 3 marta · `</ol>`.
  - Успех: `ol`, в нём ≥ 3 `li` с текстом, без номеров руками, всё закрыто.
  - Фразы: `ul` вместо `ol` («у шагов важен порядок»); номера руками; «пока пунктов: N»; текст без `li`; `li` без списка; `<ol>…</ul>`; не закрыт.
  - Подсказки: 1) порядок важен — `ol`, шаг — в `li`; 2) `ol`, три `li`, `/ol`; 3) образец про чай.
  - Дополнительная задача: шаги «Sovg'a» (как упаковать подарок).
- **Т4 · Tayyorgarlik.**
  - Код: `ol` из трёх шагов, во втором — «2. » руками. Браузер честно: «2. 2. Stollarni qo'ying».
  - Неверная строка — своя причина: шаг в порядке, номер один, ищи шаг с двумя.
  - Верная — строка становится полем, номер убрать, слова не менять.
  - Подсказки: 1) где номер два раза; 2) что лишнее внутри `li`; 3) образец шага без номера.
  - Дополнительная задача: та же поломка в третьем шаге другого списка.
- **Т5 · Mening ro'yxatim.**
  - Схема: `body` ✓ → `h1` → `ul / ol` → `li` × 3, отметки по мере набора.
  - Фразы: «страница начинается с заголовка», «для главного заголовка нужен h1», «заголовок готов, теперь список», «пока пунктов: N», номера руками, текст без `li`.
  - Подсказки: 1) по схеме; 2) список открывается и закрывается одним тегом, пункты — в `li`; 3) образец «Sevimli mevalar».
  - Дополнительной задачи нет.

## Особые правила

- Код ученика не исполняется; страница рисуется React как текст; `<`, `&` — как текст и в превью, и в артефакте.
- Честный браузер — как в уроке 3: `ol` нумерует сам; номер руками — второй; текст в списке без `li` — без точки; `li` без списка — с точкой; страница всегда помещается в окно.
- В речи `ul`, `ol`, `li` — по буквам (сборка, как в уроке 3), `h1`, `body` — по-английски; символов в репликах нет.
