**Замысел.** На сайте кинотеатра Коди стёрся CSS (классы и id в HTML остались) — ученик возвращает цвета пяти страницам, каждый раз выбирая нужные элементы селектором тега, `.class` или `#id`. HTML страницы виден справкой под браузером (в своей странице имена id и класса — в условиях «готово»).

| # | Слайд | Что делает ученик | Ответ | Ветки (своя причина) |
|---|---|---|---|---|
| 1 | крючок | «Обновить» — цвета пропадают, вкладки гаснут | — | — |
| 2 | т1 Афиша | заменить селектор в готовом правиле: красные только новинки (`p` красит все абзацы) | `.yangi { color: red; }` | `p` — красные и другие абзацы; `yangi` без точки — селектор ничего не выбрал; доп.: зелёный только мультфильм (`p` → `.multik`) |
| 3 | т2 Хит недели | вписать свойство и значение в правило `#hit { }` | `color: orange;` | не оранжевый; доп.: заголовок `#bosh` фиолетовый |
| 4 | т3 Сеансы | правило целиком: вечерние сеансы синие | `.kech { color: blue; }` | `p` — покрасились и другие абзацы; не синий; доп.: утренние зелёные (`.ertalab`) |
| 5 | т4 Билеты | починить два селектора | `narx` → `.narx`; `.Chegirma` → `.chegirma` | нет точки, большая буква — «селектор ничего не выбрал, сверь с HTML»; доп.: `kassa` → `#kassa` (нет решётки у id) |
| 6 | т5 Мой фильм | своя страница: цвет заголовка через `#nom`, ролей через `.rol`, фон `body` (условия видны и загораются) | любые цвета | нет правила для `#nom` / `.rol` / фона body; заголовок того же цвета, что фон |
| 7 | вывод | все вкладки горят, своя страница и её код; умения p / .class / #id / починка; дальше — «Цвета» | — | — |

Помощь на каждом задании: 1 — направление, 2 — правило словами (имя класса, точка или решётка), 3 — образец под кодом с другим содержимым (`.sport`, `#logo`); со второй неудачи подряд ступень открывается сама; после образца — дополнительная задача.

Честный браузер: класс сравнивается с учётом регистра (`.Chegirma` не находит `chegirma`), сила селекторов — как в браузере, поэтому в т1 и т3 на странице есть абзац без класса — `p` вместо класса не проходит.
