# Сценарий: курс JavaScript, урок 2 «Переменные»

26.11.2026. Заказчик: «делаем следующий урок js». Тема по плану: `let`, `const`, хранение данных, изменение значений.

Файл: `lessons/javascript/02-peremennye.jsx`. Сборка: `node tools/js2/build.mjs`. Канон — `canon/javascript/canon-v1.jsx`.

Облик — как урок 1: тёмный редактор `script.js`, консоль Chrome. Страницы в браузере нет (до уроков DOM — правило заказчика). **Своя картинка урока — панель «Память» (Xotira / Память / Memory)**: каждая переменная — коробка с ярлыком-именем и значением внутри; `let` открывает новую коробку, знак равно кладёт значение, новое значение падает в коробку и вытесняет старое, у `const` на ярлыке замок. Строки кода загораются по очереди, коробки и консоль меняются в тот же миг, что и строка.

Исходник — `tools/js2/`:
- `j2.src.jsx` — META, тексты `C` на трёх языках;
- `j2-engine.jsx` — движок урока 1 + переменные: `let`, `const`, `let x;`, присваивание, `+= -= *= /=`, `++ --`; ошибки как в Chrome (`ReferenceError: coin is not defined`, `Cannot access 'x' before initialization`, `TypeError: Assignment to constant variable.`, `SyntaxError: Identifier 'x' has already been declared`, `Missing initializer in const declaration`, `Unexpected identifier 'name'` — пробел в имени, `Invalid or unexpected token` — имя с цифры, `Invalid left-hand side in assignment`); присваивание без `let` создаёт глобальную переменную, как в Chrome; `jsTrace` — вывод и «Память» после каждой строки; `useTraceAnim`, `JsMem`, `JsSide`;
- `j2-screens.jsx` — экраны;
- `j2.css` — стили (поверх `../css1/c1.css` и `../js1/j1.css`).

## Замысел

- **Ситуация.** Коди делает игру «Kodi Run»: герой бежит и собирает монеты. Игре надо помнить, сколько монет, жизней, какой уровень — иначе каждое число придётся переписывать в коде руками.
- **Загадка** (Коди ошибается): «в коробке `coins` лежит 3; напишу `console.log("coins")` — и в консоли выйдет 3».
- **Разгадка:** в кавычках — просто текст, выйдет слово `coins`; значение коробки берут по имени без кавычек.

**После урока ученик:**
- создаёт переменную: `let имя = значение;` (коробка, имя, знак равно — «положить»);
- достаёт значение по имени: `console.log(имя)` без кавычек;
- меняет значение без `let`: `lives = 2;`, `lives = lives - 1;` и читает, что окажется в коробке;
- выбирает `let` (меняется) или `const` (не меняется) и чинит `TypeError: Assignment to constant variable.`;
- читает ошибки переменных: опечатка в имени, переменная раньше `let`, второй `let`.
