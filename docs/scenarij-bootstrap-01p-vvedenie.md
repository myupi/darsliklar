К уроку 1 «Введение в Bootstrap» (`lessons/bootstrap/01-vvedenie.jsx`). Файл — `lessons/bootstrap/01p-vvedenie.jsx`,
данные — `tools/bsp/p01.jsx`, сборка — `node tools/bsp/build.mjs 01`, автопроверка — `tools/qa/lesson-team/scenarios/bootstrap-01p-vvedenie.qa.mjs`
(`node tools/bsp/mkqa.mjs 01`). Каркас — `tools/bsp` (поверх каркаса практик CSS `tools/cssp`), описание — `tools/bsp/README.md`.

## Замысел

Сайт кружка роботов из урока 1: пять страниц, на каждой — e'lon Bootstrap. При обновлении пропала строка `link` — сайт голый,
вкладки погасли. Коди возвращает строку `link` на страницы 1–3, ученик восстанавливает e'lonlar. На странице 4 Коди набрал
`link` руками — с опечаткой. Пятая страница — своя.

Умения урока, которые ученик пишет сам: слово цвета `theme-*` у e'lon; два слова `alert theme-*`; взять пример с сайта
(копировать → вставить) и настроить (цвет и свой текст); починить: адрес `link` (заново с сайта) и имя версии 5; своя страница —
`link` в `head`, `script` в конце `body`. Смесь с прошлыми модулями: документ `head` / `body`, `h1` (HTML), class (CSS).
Будущих тем нет (кнопки, `fg-*`, `bg-*` — урок 2).

## Проверка (разбор `bpDiagnose`, одна причина)

Русские буквы в теге; кавычки; недописанный тег; незакрытый / лишний парный тег; строка `link`: опечатка в адресе, другая
версия, нет `rel`, чужой `integrity`; строка `script`; слова class: точка, имя версии 5 (`alert-danger`, `btn-primary`,
`text-*`, `col-md-4` …), опечатка («Balki alert demoqchisiz?» — по словам самого CSS Bootstrap), неизвестное слово. Потом — цель
задания по странице (`BpDoc`: `bs`, `link`, `script`, `theme`, `text`). Вторая неудача подряд — ступень подсказки, третья ступень —
образец под кодом, после него — дополнительная задача.

## Копирование с сайта

Карточка «getbootstrap.com» под окном браузера (задания 3–5): блок кода с подписью раздела и значком копирования («Nusxalandi»),
слова Variants. «Qo'yish» вставляет скопированное: пока ученик сам не ставил курсор — в первую пустую строку заготовки
(`link` — в head, e'lon — в body), без пустых строк — сразу после прошлой вставки (`script` — за e'lon), иначе — в курсор.
