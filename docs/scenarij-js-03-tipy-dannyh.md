# Сценарий: курс JavaScript, урок 3 «Типы данных»

26.11.2026. Заказчик: «делай следующий урок js». Тема по плану: string, number, boolean.

Файл: `lessons/javascript/03-tipy-dannyh.jsx`. Сборка: `node tools/js3/build.mjs`. Канон — `canon/javascript/canon-v1.jsx`.

Облик — как уроки 1–2: тёмный редактор `script.js`, «Память» и консоль Chrome, страницы нет (до DOM). **Новое в «Памяти»: коробка окрашена по типу значения** — string (текст) оранжевая, number (число) зелёная, boolean (true / false) синяя; под значением подписан тип. В консоли, как в Chrome, числа и true / false синие, текст — чёрный: по цвету видно, что `"10" + 5` дал текст 105, а `10 + 5` — число 15.

Исходник — `tools/js3/`:

- `j3-engine.jsx` — движок урока 2 + `true` / `false` (`True` — «True is not defined»), `typeof` («string», «number», «boolean», «undefined»; у несуществующего имени — «undefined» без ошибки), склейка строки с числом, `let a = 1, b = 2`, `2,5` вместо `2.5` — «Unexpected number»;
- `j3-screens.jsx` — экраны (общие `Predict`, `StepShow`, `TypeSort` — из урока 2);
- `j3.css` — стили (поверх `../css1/c1.css`, `../js1/j1.css`, `../js2/j2.css`).

## Замысел

- **Ситуация.** Коди сохраняет игру «Kodi Run»: имя героя, монеты, есть ли ключ. Три коробки — три разных вида данных.
- **Загадка** (Коди ошибается): «"10" плюс 5 — это пятнадцать».
- **Разгадка:** `"10"` в кавычках — текст; текст плюс число склеиваются: 105.

**После урока ученик:**
- различает string (в кавычках), number (без кавычек, считается), boolean (true / false без кавычек);
- узнаёт тип через `typeof`;
- понимает, что `"42"` и `"true"` — текст, а `True` — ошибка;
- предсказывает результат плюса: число + число складываются, текст + что угодно склеивается; чинит «5010» вместо 60;
- пишет переменную нужного типа сам.
