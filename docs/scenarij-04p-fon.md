**Замысел.** На сайте про выходной Коди стёрся CSS — ученик возвращает фон пяти страницам: цвет фона у элемента, картинка через `url("…")`, `cover`, повтор и `no-repeat`, запасной цвет. Картинки — файлы урока 4 (`maydon.jpg`, `osmon.jpg`, `futbol.png`, `yulduz.png`; свои SVG в `PR.files`), чужое имя — картинки нет.

Помощь на каждом задании: 1 — направление, 2 — правило словами, 3 — образец под кодом с другим содержимым; со второй неудачи подряд ступень открывается сама; после образца — дополнительная задача.

Какая картинка на фоне, проверка узнаёт по вычисленному `background-image` (по цвету, который есть только в этом файле). В речи знаки — словами («qavs», «qo'shtirnoq», «chiziqcha»), имена файлов — как в уроке 4.
