## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает из урока 1: style в head, правило «селектор { свойство: значение; }», селектор по тегу.
- **После урока ученик сможет:**
  1. объяснить, что селектор тега выбирает все такие элементы;
  2. дать элементу class в HTML и выбрать его в CSS через точку; один класс — на нескольких элементах;
  3. дать элементу id в HTML и выбрать его в CSS через «#»; id — один на странице;
  4. найти поломку выбора: другое имя (и регистр), «#» вместо точки, точка в HTML, нет точки.
- **Не забегаем:** несколько классов у элемента, сочетания селекторов (`p.muhim`, потомки), специфичность как тема (в браузере урока она честно действует: id > class > тег).
- **Новые слова (draft):** `panjara belgisi` («#»), `class selektori`, `id selektori`, `teg selektori`.

## Особые правила урока

- **Честный браузер.** Селектор разбирается: тег, `.class` (имя с учётом регистра), `#id`; иное (например `muhim` без точки) — тег с таким именем, ничего не выбирает. Сила — id > class > тег, при равенстве — последнее правило. Значения проверяет Chrome (`CSS.supports`).
- Телефон: окно браузера ниже, строки кода плотнее; на 360 × 640 служебные строки `style` и `body` прячутся, текст страницы в окне — до 0,52 от обычного.
