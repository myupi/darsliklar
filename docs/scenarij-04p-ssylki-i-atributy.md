## Операция

Сайт островов: у каждого острова своя страница, между ними мосты-ссылки. В хуке ученик нажимает «Шторм!» — шторм рвёт мосты, флажки островов гаснут. Ученик чинит четыре моста кодом и пишет своё меню островов. На карте остров загорается, когда его мост готов.

## Проверка и подсказки

- **Проверка по «Проверить».** Называет одну проблему. Со второй неудачи подряд к ней добавляется ступень подсказки.
- **Фразы проверки:**
  - нет ссылки;
  - нет href / пусто;
  - не тот адрес (с адресом, куда ведёт, и нужным);
  - слова ссылки поменялись;
  - нет кавычек (браузер понял, но пишем в кавычках);
  - нет «=»;
  - опечатка в имени атрибута (`hrf` → href);
  - атрибут в закрывающем теге;
  - ссылка в ссылке без `</a>`;
  - страницы нет (в своём меню).
- **Лампочка — три ступени:** направление → место или правило (в t4 — номер строки, строка подсвечена) → образец с другим содержимым. После образца — дополнительная задача:
  - t1 — адрес у «Пещеры»;
  - t2 — «Попугаи»/«Вулкан»;
  - t3 — ссылка на маяк;
  - t4 — две другие поломки (`hreff`, нет `</a>`);
  - t5 — ссылка на `index.html`.
- **Артефакт:** `{ type: 'html-page', title, text, items, html }` — меню из t5.
