## Паспорт

- lessonId `html-04p-ssylki-i-atributy`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона.
- Материал урока 4 (по файлу урока): тег `a` делает ссылку; атрибут `href` — «куда вести»; значение в кавычках — имя файла, буква в букву; `a` без `href` — простой текст (загадка урока); нет такого файла — «Fayl topilmadi»; без `</a>` ссылкой становится и текст дальше.
- Смесь:
  - с уроком 3 — меню-список (`ul`/`li`) на главной;
  - с уроком 2 — ссылка внутри абзаца `p`, своя страница с `h1` и `p`.
- Что ученик напишет сам:
  1. имя файла в `href`;
  2. ссылку целиком `<a href="…">…</a>`;
  3. абзац со ссылкой внутри;
  4. найдёт `a` без `href` и добавит его;
  5. свою страницу: `h1` и `p` со ссылкой на файл сайта.
- Лесенка письма: т1 значение (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своё по схеме (большой редактор).
- Операция: сайт Коди о путешествии — главная и страницы городов, связанные ссылками. При сохранении ссылки оборвались, названия городов стали простым текстом. Ученик чинит страницы по одной, пятая — его страница.
- **Карта — вкладки браузера**, как в 01p–03p: главная, Toshkent, Samarqand, Buxoro, Mening sahifam.
- **Ссылки в браузере нажимаются:** открывают файл сайта, адрес и вкладка меняются, стрелка «назад» возвращает; нет файла — «Fayl topilmadi». Файлы сайта: `index.html`, `toshkent.html`, `samarqand.html`, `buxoro.html`, `xiva.html`.
- Код — часть `body`, как в уроках 2–4. Разбор кода понимает атрибуты: у `a` — `href`.
- Артефакт: `{ type: 'html-page', title, heading, text, href, html }` — своя страница из т5 (тексты и адрес через `escHtml`).
- Типичные ошибки набора:
  - `a` без `href`;
  - пустой `href`;
  - нет кавычек;
  - нет `=`;
  - `hraf`;
  - нет такого файла (в том числе с большой буквы);
  - ведёт не туда;
  - не закрыт `a`;
  - текст ссылки не тот;
  - абзац без ссылки;
  - ссылка без абзаца;
  - страница без `h1` или без ссылки.
