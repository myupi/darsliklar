## Учебный замысел

Тема по плану заказчика: стиль, цвета, настроение, карточки, тени, шрифты. В промпт добавляется пятый вопрос формулы — «Ko'rinishi?» («Как выглядит?», зелёный).

После урока ученик умеет:

- описать внешний вид вместо «chiroyli»: настроение (стиль), цвета, форму карточек, тени, шрифт;
- подобрать стиль к сайту и его аудитории;
- поставить главный цвет первым;
- по сайту понять, какой у него стиль и какое описание его дало.

**Загадка.** Коди пишет для киберспортивного турнира «chiroyli bo'lsin», и ИИ делает нежно-розовый сайт, «как цветочный магазин». Коди думает: «красиво» все понимают одинаково.

**Разгадка.** «Красиво» у каждого своё: игрокам — неон, бабушке — тёплый коричневый, малышам — разноцветное. ИИ понимает только описание.

## Симулятор: что меняет «Ko'rinishi?»

`lookOf(look)` узнаёт:

- **настроение** (`LOOK_MOODS`):
  - неон;
  - ретро/пиксель;
  - тёмный;
  - весёлый;
  - спокойный (тёплый);
  - минимализм;
  - строгий;
  - современный;
- **цвета** (`LOOK_COLORS`, двенадцать):
  - первый не белый — главный (`lookPalette`);
  - второй — для кнопок;
  - белый — светлый фон;
- **форму**: скругления или прямые углы;
- **тени**: большие или без теней;
- **шрифт**: рукописный, с засечками, кода, крупный.

Что меняется на сайте (`lookCss`):

- **облик** — набор правил CSS настоящей страницы; блоки из урока 3 выглядят как карточки;
- **«chiroyli», «zo'r»** — ИИ угадывает сам: нежно-розовый спокойный дизайн, метки «Taxmin»;
- **свой «Ko'rinishi?» важнее облика под аудиторию** из урока 2;
- **метки «Ko'rinishi?»** стоят у названия, кнопки и первой карточки или блока;
- **на телефоне** окно показывает верх сайта — там видно стиль.

## Проверка ответов

Общая проверка `lookIssue`:

- пусто → «напиши»;
- «chiroyli» → «у каждого своё, опиши настроение, цвета, углы, шрифт»;
- ничего не узнано → «например…».

Дальше — своя проверка у каждого задания:

- s3 — весёлый;
- s6 — красный и зелёный, красный первым;
- s9 — рукописный шрифт и коричневый или золотой;
- s10 — неон или тёмный и зелёный;
- g1 — главный красный;
- s12 — строгий и главный синий;
- s13 — стиль, цвет, скругления, большие тени.

Промпт уходит ИИ всегда. После второй ошибки подряд открывается следующая ступень подсказки, на третьей — образец.
