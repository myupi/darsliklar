# Профиль модуля: HTML (курс «HTML · Основы разметки»)

Собран по материалам проекта на 18.10.2026, эталон обновлён 22.10.2026 (урок 1 «Бумажная страница»). Источник решений заказчика — `CLAUDE.md`; подробные правила — навыки `/novyy-urok`, `/praktika` и `docs/brif-uroka.md`. При расхождении действует приоритет из `.claude/skills/novyy-urok/references/istochniki.md`.

## 1. Предмет и аудитория
- HTML для начинающих, модуль `html-m1-osnovy`. План — `lessons/html/_course.js`: 9 уроков (последний — финальный проект, `final: true`), практика после каждого урока, кроме финального (`practice: true`).
- Готовы: урок 1 `01-struktura-dokumenta.jsx` (**главный эталон** с 22.10.2026 — «Бумажная страница», бывший тестовый 12), практика `01p-struktura-dokumenta.jsx`, урок 2 `02-zagolovki-i-tekst.jsx`. Тестовые варианты — `lessons/test/` (песочница, `sandbox: true`); прежние уроки 1 — `lessons/test/13-struktura-robot.jsx` («Робот Пиксель») и `lessons/test/09-struktura-dokumenta-kodi.jsx`.
- Ученики 10–14 лет, проходят **сами, без преподавателя**, ~90% с телефона; основная аудитория — узбекоязычные дети.

## 2. Языки
- `uz`, `ru`, `en` — все три обязательны и равноправны; переключателя в уроке нет.
- Обращение: UZ — «Siz», RU — «ты» без форм рода, EN — «you».
- Не использовать: «ошибка», «неправильно», «xato», «noto‘g‘ri». Учеников называть «веб-программист» (UZ «veb-dasturchi»), не «веб-мастер».
- Термины в узбекском: «sahifa nomi», «brauzer yorlig‘i» (не «varaqcha»); названия тегов в речи — по-английски.

## 3. Понятия: изучено и ново
Определять по плану и реальным файлам (итоговые экраны `skills` / `next`, артефакт). Сводка (`istochniki.md`, 16.10.2026):
- урок 1 — сайт из трёх слоёв (HTML · CSS · JavaScript); тег — слово в угловых скобках; открывающий тег, содержимое, закрывающий тег; `<!DOCTYPE html>`, `html` — вся страница, `head` — «паспорт страницы», `title` — вкладка, `body` — всё, что видно в окне; пары и вложенность; свой документ из 8 строк;
- урок 2 — `h1–h6` (h1 главный, h2 раздел, h3 часть раздела), `p`, `b`, `i`; переносы строк в коде не делают абзацев;
- урок 3 «Списки» — только тестовые версии (`lessons/test/04-spiski.jsx`, `05-spiski-2.jsx`); атрибуты впервые — урок 4 (`a href`).
Будущие темы не требовать никогда.

## 5. Канон и технические ограничения
- Канон `canon/html/canon-v1.jsx` копируется в урок **дословно** сверху, урок — ниже пометки «УРОК». Внутри урока канон не правится; правки — `tools/build-canon.mjs`, `canon/html/*.part.jsx`, затем `npm run canon` (только по задаче о каноне).
- Контракт: один файл, `export default`; пропсы `{ studentName, lang, ttsApiBase, voiceGender, onFinished }`; первая строка корня — `setLmsVoice(voiceGender)`; импорт только `react`; прогресс — `store` в памяти до конца урока, localStorage нет; журнал `log({ screenId, type, correct, firstTry, attempts, … })` — одна строка на экран; финиш `p.finish()`, `onFinished` ровно один раз (`useLessonRoot`); payload без оценки.
- Прочее: все тексты — в `C` / `UI` через `L3(uz, ru, en)`; объект `{uz,ru,en}` прямо в JSX ломает React; без анимации появления экрана с `opacity: 0`; классы с префиксом урока.

## 6. Готовые компоненты и сборка
- **Сборка:** исходник урока (только часть ниже «УРОК») → `node .claude/skills/novyy-urok/scripts/sobrat.mjs <исходник> <урок>` ставит канон и помощники урока 2. Общий код вручную не переписывать. Тестовым урокам канон ставит сборщик, `check-canon` их не проверяет.
- **Канон** (`canon/html/canon-v1.jsx`): `Stage` (Коди, задание, подсказка, навигация), `useLessonRoot`, `store`, `log`, озвучка, `L3`, позы Коди, хлопушки — шпаргалка в `references/realizaciya.md`, раздел «API канона».
- **Помощники урока 2** (`/*@L2_HELPERS@*/`, раздел «Помощники курса HTML» в `references/realizaciya.md`): мини-браузер `MiniBrowser` + `Page` (честное превью), строка кода с вводом `InlineInput`, ряд клавиш `KeyRow`, рабочая область `Work`, инспектор `Inspector`, рука-подсказка `DemoHand`, викторина `Quiz`, порядок `Reorder`, сортировка касанием `TapSort`, экраны миссии и достижений `MissionScreen` / `AchievementScreen`. Каркас экрана — раздел «Экран — каркас».
- **Бумажный набор эталона урока 1** (`tools/kollazh/`: `kollazh-kit.jsx`, `kollazh-trans.jsx`, `kollazh-paper.jsx`, `kollazh.css`): вырезки `Cut`, лист `Sheet`, строка задания `KzAsk`, теги `KzLabel`, код `KzCode` (с местами и ▲▼), бумажный браузер `PaperBrowser`, перетаскивание `useKzDrag`, рука-показ `KzHand`, перелёт `kzFly`, переход `useKzTransition`, шорох `usePaperSound` — **подключать** в исходник урока через `/*@FILE:../kollazh/…@*/` (`references/etalon-bumazhnaya.md`, раздел 7).
- **Браузер — плоский, как Chrome в Windows** (вкладка с фавиконом и крестиком, «+», кнопки окна, страница); в новых уроках — бумажный `PaperBrowser` эталона. Монитор, киоск и другие «рамки-устройства» заказчик отклонил (19.10.2026).
- **Механики подбираются под тему:** готовые помощники — материал, а не шаблон урока. Не хватает механики для сценария — назвать её и вынести отдельной задачей со сроком; не начинать новую библиотеку.

## 7. Персонажи и визуальный язык
- Герой курса — **Коди** (с 17.10.2026 только голова в белом кружке, рисунок v4; позы меняют лицо, речь — волны вокруг кружка). В практике Коди не рисуется.
- **Бумажный человечек** — образ урока 1 (эталон). В других уроках — свой бумажный образ темы; робот Пиксель и объёмные фигуры anatomy — решения прежнего урока 1 (теперь тестовый 13).
- Каркас канона: фон `#F6F4EF`, интерфейс оранжевый; рабочая область — бумажный лист эталона (`references/etalon-bumazhnaya.md`, раздел 2); «верно» — зелёный, подсказка — жёлтый, красного цвета ошибки нет. Шрифты: Manrope, JetBrains Mono (код), Times (страница в мини-браузере). Цвета тегов `TAGC` — таблица в `references/vizual-i-ux.md` навыка.
- Код HTML всегда рядом с честным мини-браузером (как Chrome), без переключателя «Код / Результат».

## 8. Озвучка
- Движок канона по `ttsApiBase` (исключение 12.10.2026): маркер языка `[O'zbekcha tallaffuz]` / `[Русское произношение]` / `[English pronunciation]` и тег эмоции ставит движок.
- Реплики: полные предложения, до ~25 с; без символов `% / ² + = ×`; без имени ученика; названия тегов — английскими словами во всех языках (`body`, «H one»); начинать с живого слова («Огонь!», «Почти!»), чтобы сработала эмоция.
- Урок проходится без звука: задание всегда написано, у гейтов есть предохранители.

## 9. Типы заданий и проверок
- Механики канона и курса — `docs/brif-uroka.md`, «Механики»; помощники урока 2 — `references/realizaciya.md`.
- Настоящая работа с кодом обязательна: изменить, написать, проверить, исправить. Касания и выборы — подготовка.
- Предметная проверка: честное превью (как настоящий браузер), разбор набранного кода, перенос «без образца», своя страница с видимыми условиями «готово».
- Типичные ошибки: нет `/` в закрывающем теге, не тот тег, не на месте, не закрыт; ложные представления («Enter делает абзац»).
