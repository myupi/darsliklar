# Профиль модуля: HTML (курс «HTML · Основы разметки»)

Собран по материалам проекта на 18.10.2026. Источник решений заказчика — `CLAUDE.md`; подробные правила — навыки `/novyy-urok`, `/praktika` и `docs/brif-uroka.md`. При расхождении действует приоритет из `.claude/skills/novyy-urok/references/istochniki.md`.

## 1. Предмет и аудитория
- HTML для начинающих, модуль `html-m1-osnovy`. План — `lessons/html/_course.js`: 9 уроков (последний — финальный проект, `final: true`), практика после каждого урока, кроме финального (`practice: true`).
- Готовы: урок 1 `01-struktura-dokumenta.jsx`, практика `01p-struktura-dokumenta.jsx`, урок 2 `02-zagolovki-i-tekst.jsx`. Тестовые варианты — `lessons/test/` (песочница, `sandbox: true`).
- Ученики 11–14 лет, проходят **сами, без преподавателя**, ~90% с телефона.

## 2. Языки
- `uz`, `ru`, `en` — все три обязательны и равноправны; переключателя в уроке нет.
- Обращение: UZ — «Siz», RU — «ты» без форм рода, EN — «you».
- Не использовать: «ошибка», «неправильно», «xato», «noto‘g‘ri». Учеников называть «веб-программист» (UZ «veb-dasturchi»), не «веб-мастер».
- Термины в узбекском: «sahifa nomi», «brauzer yorlig‘i» (не «varaqcha»); названия тегов в речи — по-английски.

## 3. Понятия: изучено и ново
Определять по плану и реальным файлам (итоговые экраны `skills` / `next`, артефакт). Сводка (`istochniki.md`, 16.10.2026):
- урок 1 — `<!DOCTYPE html>`, `html`, `head`, `title`, `body`; открывающий и закрывающий тег; вложенность; title — вкладка, body — страница;
- урок 2 — `h1–h6` (h1 главный, h2 раздел, h3 часть раздела), `p`, `b`, `i`; переносы строк в коде не делают абзацев;
- урок 3 «Списки» — только тестовые версии (`lessons/test/04-spiski.jsx`, `05-spiski-2.jsx`); атрибуты впервые — урок 4 (`a href`).
Будущие темы не требовать никогда.

## 5. Канон и технические ограничения
- Канон `canon/html/canon-v1.jsx` копируется в урок **дословно** сверху, урок — ниже пометки «УРОК». Внутри урока канон не правится; правки — `tools/build-canon.mjs`, `canon/html/*.part.jsx`, затем `npm run canon` (только по задаче о каноне).
- Сборка нового файла: `node .claude/skills/novyy-urok/scripts/sobrat.mjs <исходник> <урок>` (канон + помощники урока 2). Тестовым урокам канон ставит сборщик, `check-canon` их не проверяет.
- Контракт: один файл, `export default`; пропсы `{ studentName, lang, ttsApiBase, voiceGender, onFinished }`; первая строка корня — `setLmsVoice(voiceGender)`; импорт только `react`; прогресс — `store` в памяти до конца урока, localStorage нет; журнал `log({ screenId, type, correct, firstTry, attempts, … })` — одна строка на экран; финиш `p.finish()`, `onFinished` ровно один раз (`useLessonRoot`); payload без оценки.
- Прочее: все тексты — в `C` / `UI` через `L3(uz, ru, en)`; объект `{uz,ru,en}` прямо в JSX ломает React; без анимации появления экрана с `opacity: 0`; классы с префиксом урока.

## 6. Персонажи и визуальный язык
- Герой курса — **Коди** (с 17.10.2026 только голова в белом кружке, рисунок v4; позы меняют лицо, речь — волны вокруг кружка). В практике Коди не рисуется.
- **Пиксель** — робот тестового урока 07 (`lessons/test/07-struktura-robot.jsx`); **не утверждён** как персонаж курса. Использовать, только если задача продолжает эту историю.
- Фон `#F6F4EF`, карточки белые, интерфейс оранжевый, «верно» — зелёный, подсказка — жёлтый, красного цвета ошибки нет. Шрифты: Manrope, JetBrains Mono (код), Times (страница в мини-браузере). Цвета тегов `TAGC` — таблица в `references/vizual-i-ux.md` навыка.
- Код HTML всегда рядом с честным мини-браузером (как Chrome), без переключателя «Код / Результат».

## 7. Озвучка
- Движок канона по `ttsApiBase` (исключение 12.10.2026): маркер языка `[O'zbekcha tallaffuz]` / `[Русское произношение]` / `[English pronunciation]` и тег эмоции ставит движок.
- Реплики: полные предложения, до ~25 с; без символов `% / ² + = ×`; без имени ученика; названия тегов — английскими словами во всех языках (`body`, «H one»); начинать с живого слова («Огонь!», «Почти!»), чтобы сработала эмоция.
- Урок проходится без звука: задание всегда написано, у гейтов есть предохранители.

## 8. Типы заданий и проверок
- Механики канона и курса — `docs/brif-uroka.md`, «Механики»; помощники урока 2 — `references/realizaciya.md`.
- Настоящая работа с кодом обязательна: изменить, написать, проверить, исправить. Касания и выборы — подготовка.
- Предметная проверка: честное превью (как настоящий браузер), разбор набранного кода, перенос «без образца», своя страница с видимыми условиями «готово».
- Типичные ошибки: нет `/` в закрывающем теге, не тот тег, не на месте, не закрыт; ложные представления («Enter делает абзац»).

## 9. Результат ученика
- `extraPayload`: страница `{ type: 'html-page', title, …, html }` или сайт `{ type: 'html-site', pages: [{ name, title, html }] }`; HTML — полный документ урока 1, текст ученика экранирован.
