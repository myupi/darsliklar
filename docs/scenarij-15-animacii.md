- Основа кода — урок 14 курса CSS (`tools/css14/`). Новое в движке `CssPage`:
  - **настоящие `@keyframes`.** `kfParse` разбирает блок, кадры пишутся в `<style>` внутри страницы, анимацию крутит сам браузер.
    - Имена получают приставку страницы: на экране бывает две страницы с одинаковыми именами.
    - В `animation` приставка ставится только к объявленным именам. Имя с опечаткой или с другим регистром остаётся как есть — браузер, как в жизни, ничего не находит.
    - Кадр «50» без % отбрасывается.
  - **анимация начинается заново на каждом шаге**: у элементов новый ключ, когда меняются правила или кадры;
  - **полоса анимаций** (`TimeBar`) — по событию `animationstart` и `getComputedStyle`: имя, секунды, повторы (∞ или ×N). Полоса бежит так же, как анимация: то же время, скорость, повторы и направление. Имя без своего `@keyframes` — серая зачёркнутая строка «—»;
  - **проверка значения `animation` самим браузером** (`animOf`, через `style.animation`): порядок слов любой;
  - **блок `@keyframes` в редакторе** (`ruleLines`): заголовок, кадры, скобка. Поле ввода может стоять прямо в кадре (`CodeFill`, метки ▢);
  - **основа кубика свёрнута** в `.kub { … }`, иначе код не влезает в телефон. Целиком она — на странице и в артефакте;
  - **своё поле ввода `LessonInput`** (копия `InlineInput`): подгонка размера — в следующем кадре. Рядом с блоком `@keyframes` рост поля переносит строку, и подгонка внутри наблюдателя зацикливала ResizeObserver. Общий набор не тронут;
  - **слой `position: fixed`** (урок 12) рисуется только когда нужен: пустой, он растягивался на всё окно и мешал ужатию страницы.
- Тексты — по `/uzbekcha`: апостроф ASCII, «ya'ni … degani», загадка без имён.

## Паспорт

- **Ученик:** 11–14 лет, проходит сам, чаще с телефона. Уже знает правило, селекторы, Box Model, Flexbox, позиционирование, `:hover`, `transform`, `transition` (уроки 1–14).
- **После урока ученик сможет:**
  1. написать план движения `@keyframes имя { from { … } to { … } }` и кадры в процентах (0%, 50%, 100%);
  2. запустить его: `animation: имя время`; повторы — число или `infinite`;
  3. выбрать скорость (`linear`) и направление (`alternate`); отличить `animation` (само) от `transition` (под мышкой);
  4. найти поломку: имя с опечаткой или другим регистром, нет времени, кадр без %.
- **Не забегаем:** `animation-delay`, `fill-mode`, `steps()`, несколько анимаций через запятую.
- **Новые слова (черновые):** `harakat rejasi` (@keyframes), `kalit kadrlar` (keyframes), `animatsiya`, `cheksiz` (infinite), `borib-qaytish` / `navbatma-navbat` (alternate), `tekis` (linear), `foiz` (%).

## Особые правила урока

- **Честный браузер.**
  - Анимации и кадры настоящие.
  - Полоса анимаций — по событиям браузера.
  - Разгадка показана настоящим поведением CSS: имена анимаций различают большие и маленькие буквы.
- **Основа страницы** — свёрнутая тусклая строка `.kub { … }` (оранжевый кубик 40×40).
- **Телефон:**
  - шрифт кода мельче, окно браузера ниже;
  - на экранах «впиши» с открытой панелью окно ещё ниже, а до 799 px высотой прячется — после «Попробовать ещё» возвращается;
  - в выводе нет человечка, а в разгадке блок `@keyframes` свёрнут.
- В речи названия свойств и значений — по-английски (правка речи в `build.mjs`: `keyframes`, `animation`, `infinite`, `alternate`). Слова `from` и `to` в список не входят: «to» задело бы узбекские «to'g'ri», «to'q».
