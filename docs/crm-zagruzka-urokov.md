## Что сделано под платформу (для всех уроков)

Канон (`tools/build-canon.mjs`, `swapLmsPlatform`) и общий набор облика (`tools/redaktor28/nabor.mjs`):
- хуки платформы берутся `import * as LESSON_RT from '@lesson/runtime'` и зовутся, только если они есть
  (на go.junior-it.uz runtime старый — без `useLessonPerf`; урок там открывается без ошибки);
- `markFirstScreenReady` — один раз за открытие (`useLmsPlatform`);
- шрифт Inter — ресурсами WOFF2 через `useResources().loadFont` (раньше — base64 в CSS); Nunito убран (не используется);
- шапка урока начинается с 52 px — ярлык раздела не под кнопкой «X» LMS (B09);
- переменные модуля, которые урок сбрасывает сам, помечены `// jsx-tekshir: ataylab` (Y09);
- файлы шрифтов кладёт рядом с уроком сборщик `sobrat.mjs` (`lessons/<курс>/assets/<урок>/`).

Озвучка — как в Dars001: урок сам заказывает каждую реплику у сервиса по `ttsApiBase` (`voice_id`, `ttsKey`,
`student_uuid`), без сервиса — голос браузера. Правила IT-пакета требуют `useAudio` + `LESSON_AUDIO` — это решение заказчика.

## Предупреждения, которые остаются (для поля «Izoh»)

- **M01 `.at`** — ложное срабатывание: это поле объекта `c.at`, а не метод `Array.at()`.
- **M02** — современный CSS (`gap` у flex, `dvh`, `:has()`, `color-mix()`, `inset` и др.): на Chromium/WebView 79
  раскладка может отличаться. Облик курса построен на нём, запасных правил нет.
- **B08** «текст может быть обрезан» — в тестах «ИИ» окно сайта нарочно показывает часть сайта (иначе он мельче
  читаемого); в практиках 06p–08p строка задания видна целиком (проверено снимками на 390 px).

Не проверяется автоматически (проверить в Preview и тестовым учеником): Finish до конца (B10), перезагрузка и
`passed:false` (B19), открытие следующего урока и коины (Q01), озвучка (Q02), настоящий телефон (Q03).

## Как проверить самому

```bash
node jsx-tekshir/jsx-tekshir.mjs <урок>.jsx --assets <папка шрифтов> --kontrakt v1 --brauzer
node jsx-tekshir/jsx-tekshir.mjs <тест>.jsx --tur savol --brauzer
```

Pillow для `ornat.sh` на Python из Homebrew ставится только в отдельное окружение (PEP 668).
