## Сверено с настоящей Tilda (24–25.11.2026)

- У блока, на который навели курсор (на телефоне — нажали), есть панель:
  - слева: шифр «TX01 ▾», «Настройки», оранжевая «Контент»;
  - справа: копировать, удалить, выключить, ▾, ↑, ↓.
- Между блоками стоит чёрный «+».
- Удаление срабатывает сразу, без вопроса.
- ↶ в верхней полосе возвращает удалённый блок.
- Все блоки разделов «Заголовок» (TL), «Текстовый блок» (TX, QT) и «Изображение» (IM01, IM02) есть на бесплатном тарифе.
- Тексты новых блоков у Tilda по умолчанию английские.

## Замысел

- **Ситуация.** RoboKlub пишет: «одной обложки мало — после неё заголовок, картинка, текст о клубе».
- **Загадка** (Коди ошибается): «новый блок встаёт только вниз, переставить его нельзя, ошибся — всё заново».
- **Разгадка:** «+» ставит блок в нужное место, стрелки переставляют, ↶ возвращает удалённое.

**После урока ученик:**
- знает, что такое блок и его шифр (CR — обложка, TL — заголовок, TX — текст, IM — картинка) и как шифр связан с разделом библиотеки;
- добавляет блок через «ВСЕ БЛОКИ»: раздел, потом карточка;
- отличает текстовый блок от цитаты;
- меняет текст блока прямо на странице;
- знает кнопки блока: копировать, удалить, выключить, ↑, ↓;
- добавляет блок через «+» под нужным блоком;
- переставляет блок стрелкой;
- удаляет лишний блок;
- отменяет ошибку стрелкой ↶;
- повторяет всё на своём сайте в настоящей Tilda.
