**Замысел.** Сайт клуба Коди сверстан для компьютера (баннер 700px, расписание 500px, карточки в ряд — в `PR.base`, ученику не видны); CSS для телефона стёрся — на телефоне баннер вылез, карточки сжались. Все задания — в окне телефона шириной 360px (`vw: 360`): страница рисуется этой ширины и уменьшается целиком, `@media` браузер проверяет по ширине рамки. Проверка — по живой странице: вылезает ли элемент за окно, стоят ли карточки друг под другом, `display`, правила внутри `@media` и их условие (граница меньше 800px — на компьютере правило спит). Сверху у страницы отступ под ярлык «360px».
