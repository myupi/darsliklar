# Урок 2 (проба) · «Заголовки и текст: монитор турнира» · курс HTML / модуль 1

Тестовый урок: `lessons/test/09-zagolovki-monitor.jsx`, исходник — `tools/zagolovki/`.
Сделан по образцу тестового урока 07 (робот Пиксель): объёмная фигура навыка anatomy в центре
урока, каждое понятие объясняется там, где появляется. Сюжет и механики не повторяют урок 2 курса
(робофутбол, стена текста).

## Паспорт
- lessonId: `test-html-zagolovki-monitor`; module: `html-m1-osnovy`; возраст 11–14, без преподавателя.
- Ученик уже знает (урок 1, тестовый 07): каркас `html / head / title / body`; тег — слово в угловых
  скобках, ярлык для браузера; парные теги, закрывающий — с косой чертой; title — название вкладки,
  body — то, что видно в окне. Страница игры «Битва знаний» — из урока 07.
- Ещё не знает (не требовать): списки, ссылки, CSS, атрибуты, `br`, `strong` / `em`.
- Результаты — после урока ученик сможет:
  1) сделать главный заголовок страницы тегом `h1` и знает, что он один;
  2) выбрать уровень заголовка `h2` / `h3` по плану страницы (раздел / подраздел);
  3) разбить текст на абзацы тегом `p` — переносы строк в коде браузер не видит;
  4) выделить важные слова тегами `b` и `i`;
  5) написать свой раздел: заголовок, абзац, жирное слово.
- Новые понятия и как их показать: заголовок `h1` (название становится огромным на мониторе →
  потом слово), уровни `h1–h6` (цифра меняет размер на мониторе → «цифра — важность»), абзац `p`
  (две склеенные фразы расходятся → потом слово), `b` / `i` (слово становится жирным / наклонным).
- Типичные затруднения → где: «переносы в коде = абзацы» (экран 3, эксперимент); уровень по размеру,
  а не по смыслу (экран 6, план); незакрытый тег «съедает» страницу (экраны 7 и 10); два `h1`
  (экран 10); заголовок вместо абзаца ради крупного текста (экран 10); забыл косую черту (7, 11).
- Ситуация и роль ученика: в школьном зале турнир «Битва знаний», правила показывают на большом
  мониторе. Коди вставил текст, и он слипся в комок — из зала ничего не прочитать. Ученик —
  веб-программист турнира: делает страницу читаемой. Коди — напарник, который ошибается.
- Главная механика (изюминка): **монитор-фигура**. Страница живёт на экране настоящего монитора
  (корпус — навык anatomy, экран — живой мини-браузер в плоскости стекла). Каждое изменение кода
  сразу видно на мониторе; страница растёт от экрана к экрану.
- Финальный артефакт (payload): `{ type: 'html-page', title, blocks, html, mine: { head, text, bold } }`.
- Система слов: заголовок — `h1…h6`, главный заголовок — `h1`; раздел — `h2`, подраздел — `h3`;
  абзац — `p`; жирный — `b`, курсив — `i`. «Тег» — как в уроке 1.

## Дуга
Крючок (монитор: комок → порядок) → план → эксперимент «Enter в коде» → `h1` (показ) → шесть
уровней (показ) → разделы и подразделы по плану (повторение) → закрыть `</h2>` (письмо) → абзацы
`p` (показ + повторение) → жирный и курсив (показ + повторение) → детектив: страница финала
(проверка) → написать строку заголовка целиком (перенос) → свой раздел (своё) → финал на мониторе.

### 1. s1 · HOOK · «Монитор в зале»
- Цель: увидеть проблему (комок текста) и обещание (порядок) без терминов.
- Видит: монитор на подставке, экран тёмный. voiceTop — нет.
- Действие: «Включить монитор» (кнопка или нажатие на монитор), затем «Навести порядок».
- После: индикатор загорается, экран вспыхивает, на нём вкладка «Битва знаний» и сплошной комок
  текста. После второй кнопки комок распадается: огромное название, разделы, абзацы, выделения.
- Успех: обе кнопки нажаты. Подсказки: светодиоды на кнопке.
- Реплики: Коди в `sorry` — вставил правила, они слиплись; после порядка `wonder` — «название видно
  с последнего ряда; к концу урока сделаешь так сам».
- Журнал: нет; store s1.

### 2. s2 · MISSION — пять карточек на языке результата (огромное название, разделы, текст
кусочками, важные слова, свой раздел).

### 3. s3 · PREDICT · «Enter в коде»
- Цель: переносы строк в коде браузер не видит — нужны теги.
- Видит: код body — строки правил без тегов; монитор — комок. Кнопка-клавиша «Enter».
- Действие: нажать «Enter» — в коде между строками появляются пустые строки.
- После: монитор вспыхивает «обновлено», но комок тот же. Коди: «браузер склеивает строки; чтобы он
  понял, где заголовок и где абзац, нужны теги».
- Успех: одно нажатие. Журнал: нет; store s3.

### 4. s4 · SHOW · «Главный заголовок»
- Видит: код строк, светится строка «Битва знаний»; монитор — комок.
- Действие: нажать строку названия → вокруг неё въезжают `<h1>` и `</h1>`, на мониторе название
  становится огромным.
- Реплика после: «h1 — главный заголовок, h — heading. Он на странице один».
- Затруднение: нажата другая строка → тряска, «название игры — первая строка».

### 5. s5 · SHOW · «Шесть уровней»
- Действие: кнопки h1…h6 у строки «Правила»; надо попробовать все шесть.
- После: размер «Правил» на мониторе меняется сразу, в коде меняется цифра в обоих тегах.
- Итог: «цифра — важность: 1 главный, 6 самый мелкий; выбирают по смыслу, не по размеру».

### 6. s6 · LEVEL-1 · «Разделы и подразделы»
- Видит: план турнира (Битва знаний → Правила → Подсказки; Призы), код с `<h?>` у трёх заголовков.
- Действие: выбрать уровень для каждого (h1…h4), по очереди.
- Успех: Правила h2, Подсказки h3, Призы h2.
- Затруднение: h1 → «h1 уже есть — название игры»; h3 у раздела → «раздел стоит прямо под
  названием»; h2 у подраздела → «Подсказки — часть Правил».
- Подсказки: 1) посмотри на план; 2) разделы — h2, их части — h3; 3) конкретный ответ для строки.

### 7. s7 · LEVEL-2 · «Закрой заголовок»
- Видит: `<h2>Призы` без закрывающего тега — на мониторе весь текст после него огромный и жирный.
- Действие: набрать `</h2>` (поле в строке кода + клавиши `< / h 2 >`).
- Ответы: без косой черты, без уголков, не та цифра — своя подсказка.
- После: монитор приходит в порядок.

### 8. s8 · LEVEL-3 · «Абзацы»
- Видит: две фразы под «Правилами» склеены в одну строку на мониторе.
- Действие: нажать каждую из двух строк кода → `<p>…</p>`, фразы расходятся.
- После первой: «p — абзац, кусок текста об одном»; после второй — Коди сам оборачивает остальные.

### 9. s9 · LEVEL-4 · «Важные слова»
- Раунд 1: выделить «тридцать секунд» и нажать `<b>`. Раунд 2: название книги — `<i>`.
- Слова выбираются касанием первого и последнего слова; неверный диапазон или не та кнопка —
  подсказка с причиной.

### 10. s10 · CHECK · «Страница финала»
- Видит: страница финала для второго монитора; проверка по трём правилам: один `h1`; открытый тег
  закрыт; обычный текст — в абзаце.
- Действие: нажать строку с поломкой → выбрать исправление из двух.
- Поломки: второй `h1` («Команды» → h2), `<b>` без закрытия (вся страница жирная → `</b>` после
  слова), длинная фраза в `h2` (→ p).

### 11. s11 · TRANSFER · «Новый раздел»
- Действие: в пустой строке написать целиком `<h2>Финал</h2>` (поле + клавиши).
- Монитор показывает набранное вживую. Текст — любой осмысленный, опечатки не важны.
- Ответы: нет тегов; h1 / h3 вместо h2; нет закрывающего; нет косой черты.

### 12. s12 · RESULT · «Свой раздел»
- Условия «готово» видны списком: заголовок раздела; абзац; одно слово жирным.
- Действие: написать заголовок в `<h2>`, текст в `<p>`, нажать слово своего абзаца → `<b>`.

### 13. s13 · ACHIEVEMENT — монитор зала со страницей ученика, что получилось, следующий урок
(списки). Здесь `p.finish`.

## Арт и анимации
- Монитор (`tools/zagolovki/monitor.figures.mjs`): подставка, шея с шарниром, корпус с задней
  крышкой, рамка, стекло с бликом, камера, табличка JUNIOR IT, индикатор питания, кнопки.
  Экран — живой мини-браузер, развёрнутый 2D-матрицей по трём углам стекла.
- Включение: индикатор зеленеет, стекло вспыхивает, страница проявляется.
- Изменение кода: изменённый блок вспыхивает цветом тега, экран сам прокручивается к нему.
- На телефоне в рабочих экранах — монитор без подставки (крупнее), в крючке и финале — целиком.

## Особые правила урока
- Помощники урока 2 курса (`/*@L2_HELPERS@*/`) + свой компонент `Monitor`.
- Превью честное: строки без тегов склеиваются; незакрытый заголовок или `b` захватывает текст ниже.
- Озвучка: теги по-английски (H one, P, B, I).
