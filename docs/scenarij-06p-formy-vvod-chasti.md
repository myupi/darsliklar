- **Часть 1 без placeholder, label и form** — ни в репликах, ни в коде, ни на страницах, как и часть 1 урока: страница — `h1`, подпись в `p`, поле `input` на своей строке. Исключение — одна фраза вывода с интригой на часть 2.
- Лесенка письма: часть 1 — вписать значение в `type` → дописать атрибут `type` целиком → написать строку `input` с `type` → найти опечатку в значении `type`; часть 2 — строка `input` с `type` и `placeholder` → `label` с подписью и полем → найти поле пароля со «спрятанным» через placeholder паролем → своя анкета.

  - Успех: в поле вписан атрибут `type="number"`; на странице сразу появляются стрелки. Проверка по разбору строки `<input …>`; лишние атрибуты не ломают.
  - Фразы: пусто — «нет type»; уголки — «здесь нужен только атрибут: уголки в коде уже стоят»; одно значение (`number`) — «нужен весь атрибут: имя, знак равенства, значение в кавычках»; без кавычек — «значение пиши в кавычках»; без знака равенства; чужое имя атрибута — «такого атрибута нет, нам нужен type»; незнакомый или другой вид.
  - Подсказки: 1) type говорит, каким будет поле; впиши сам атрибут, уголки уже в коде; 2) атрибут из трёх частей: имя, знак равенства, значение в кавычках — имя `type`, значение `number`; 3) образец `<input type="password">`.
  - Дополнительная задача: «Shaxmat», поле пароля — вписать `type="password"`.
- **Т3 · Suzish** (строка `input` целиком).

  - Фразы: `</input>` — «input не закрывается»; другой вид (`password`) — «это другой вид»; другой тег (`p`, `form`) — «здесь нужен тег input»; больше одного поля; лишний текст.
  - Подсказки: 1) поле ставит input, имя могут видеть все, значит `type` будет `text`; 2) порядок: слово input, атрибут type, в кавычках text, правый уголок; 3) образец `<input type="number">`.
  - Дополнительная задача: «Rasm chizish», поле возраста — строка с `type="number"`.
- **Т4 · Raqs** (новое: найти и исправить).

  - Подсказки: 1) пароль виден — какое поле для пароля; 2) строка этого поля: что в `type`, все ли буквы на месте; 3) образец `<input type="password">` и перечень видов под окном.
  - Дополнительная задача: «Robototexnika», опечатка `passwrod` (буквы переставлены).
  - После решения страница уходит в артефакт части 1 (`myCode`, `myHead`, `myFields`, `myTab`).
