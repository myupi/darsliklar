# Сценарий: модуль Bootstrap, урок 3 «Загрузка и изображения» (20.11.2026)

Файл урока: `lessons/bootstrap/03-zagruzka-i-izobrazheniya.jsx`, сборка `node tools/bs3/build.mjs`. Облик «Редактор»,
канон — `canon/bootstrap/canon-v1.jsx`. Основа кода — урок 2 (`tools/bs2/`): честная страница с настоящим
`bootstrap.min.css` 6.0.0-alpha.1, похожий сайт Bootstrap, курсор показов, задания с полем раундами. Решения заказчика —
`CLAUDE.md`, «Модуль Bootstrap» (не меньше 17 слайдов, новое действие на сайте — сначала показом «как на видео»).

Классы сверены с getbootstrap.com/docs/6.0 и с самим CSS (20.11.2026):
- картинки (Content → Images): `img-fluid` (`max-width: 100%; height: auto`), `img-thumbnail`; сам Bootstrap 6 картинку
  не сжимает — без `img-fluid` большая картинка честно вылезает за экран телефона;
- углы (Utilities → Border radius): `rounded`, `rounded-circle`, `rounded-pill`, `rounded-0` … `rounded-9`,
  `rounded-top` и др.; в версии 3 было `img-responsive`, `img-circle` — в 6 не работают;
- спиннер (Components → Spinner): `<div class="spinner-border" role="status"><span class="visually-hidden">Loading…</span></div>`,
  `spinner-grow`, `spinner-sm`; цвет — словом `fg-*` (урок 2);
- заглушка (Components → Placeholder): `<span class="placeholder col-6"></span>`, анимация — `placeholder-wave` у родителя
  (`placeholder-pulse`; старое `placeholder-glow` — синоним); без ширины `col-…` заглушка не видна (ширина 0).

## Что ученик уже знает

Уроки 1–2: сайт getbootstrap.com, меню, копирование строки и слова, CDN, Alert, кнопки (`btn-solid` / `btn-outline` +
`theme-*`), `fg-*`, `bg-*`. HTML: `img`, `src`, `alt`; CSS: `width`, `max-width` в % (урок CSS 6), `border-radius` (урок CSS 8),
анимации (урок CSS 15).

## Учебные результаты

После урока ученик сможет:
1. сделать, чтобы большая картинка помещалась в экран телефона (`img-fluid`), и объяснить, почему без него она вылезает;
2. скруглить углы картинки и сделать круглое фото (`rounded`, `rounded-circle`, `rounded-pill`);
3. показать, что сайт загружается: спиннер (`spinner-border`, `spinner-grow`, цвет `fg-*`) и заглушки (`placeholder`,
   `placeholder-wave`);
4. найти всё это на сайте Bootstrap: Content → Images, Utilities → Border radius, Components → Spinner и Placeholder.

## Затруднения и где они разобраны

- «Для каждого телефона нужна своя маленькая картинка» — загадка Коди в крючке, разгадка в выводе.
- `img-fluid` растягивает маленькую картинку — опыт x1: только уменьшает, больше своего размера не становится.
- Старые имена (`img-responsive`, `img-circle`) — t1, t6.
- `rounded-circle` у прямоугольной картинки — овал, а не круг (показ s5).
- Заглушка без ширины не видна — t6.
- Спиннер без `role="status"` и текста для экранного диктора — показ g3 (одной фразой).

## Образ и сюжет

Сайт «Robot to'garagi» получает страницу «Bizning robotlar»: большое фото робота, фото тренера, галерея. На телефоне фото
вылезает за экран, а пока фото грузятся, страница пустая. Ученик с Коди чинит: картинки помещаются, углы круглые, пока
грузится — крутится спиннер и бегут серые заглушки. Загадка (Коди ошибается, без имён): «чтобы фото поместилось на
каждый телефон, надо сохранить для каждого свою маленькую копию». Разгадка: один `img-fluid` подгоняет фото под любой
экран.
