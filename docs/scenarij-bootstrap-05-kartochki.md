# Сценарий: модуль Bootstrap, урок 5 «Карточки» (20.11.2026)

Файл урока: `lessons/bootstrap/05-kartochki.jsx`, сборка `node tools/bs5/build.mjs`. Облик «Редактор», канон —
`canon/bootstrap/canon-v1.jsx`. Основа кода — урок 4 (`tools/bs4/`): честная страница с настоящим `bootstrap.min.css`
6.0.0-alpha.1, экран заданной ширины, картинки `FILES`, похожий сайт Bootstrap, курсор показов, задания с полем раундами.

Сверено с getbootstrap.com/docs/6.0/components/card/ и с CSS (20.11.2026):
- пример на сайте: `<section class="card" style="max-width: 320px">`, `<img src="..." class="card-img-top" alt="...">`,
  `<div class="card-body">` с `<h4 class="card-title">`, `<p class="card-text">` и `<a href="#" class="btn-solid theme-primary">`;
- `.card` — рамка, скругление, flex-колонка; `.card-body` — отступы и «ставит детей в колонку с одинаковым gap»;
  `.card-img-top` — ширина 100% и скруглённый верх;
- **`card-title` и `card-text` в CSS версии 6 правил не имеют** — это имена (как на сайте), вид даёт `card-body`; в уроке
  это видно честно (опыт x1);
- цвет: `card theme-*` — рамка и линия под фото цвета темы, фон остаётся белым (так в CSS 6.0.0-alpha.1; исправлено 23.11.2026 — Коди говорил «карточка целиком»), `card card-subtle theme-*` — рамка мягкого цвета;
- несколько карточек в ряд — `d-flex gap-*` из урока 4 (сетка `row`/`col` — урок 6).

## Что ученик уже знает

Уроки 1–4: сайт и копирование блока кода, `btn-solid theme-*`, `theme-*`, `img-fluid`, `rounded`, `d-flex`, `gap-*`,
`flex-wrap`. CSS 8 «Красивые карточки»: `border-radius`, `box-shadow`, `padding`.

## Учебные результаты

1. собрать карточку из `card`, `card-img-top`, `card-body` и объяснить, что даёт каждая часть;
2. найти на сайте страницу Card, скопировать пример и настроить: своё фото (`src`), текст, цвет кнопки;
3. покрасить рамку карточки (`theme-*`, `card-subtle`);
4. поставить карточки в ряд `d-flex gap-*`.

## Затруднения

- «Каждой вещи внутри нужен свой class, иначе карточка развалится» — загадка, разгадка: держат `card` и `card-body`,
  `card-title` и `card-text` — имена (опыт x1).
- Скопировали пример и не поменяли `src="..."` — картинка сломана (показ s5, t6).
- Текст прилип к рамке — нет `card-body` (x1, t6).
- Порядок внутри карточки: фото сверху, текст в `card-body` (сборка t4).

## Образ и сюжет

Страница «Bizning robotlar» сайта кружка: у каждого робота фото, имя, описание и кнопка — но всё свалено в кучу. Ученик
с Коди делает аккуратные карточки, красит их и ставит в ряд. Загадка (Коди ошибается, без имён): «чтобы карточка не
развалилась, каждому кусочку внутри нужен свой class». Разгадка: главное — `card` и `card-body`; `card-title` и
`card-text` в шестой версии только имена.
