# Сценарий: курс JavaScript, урок 5 «Условия — 1 часть»

26.11.2026. Заказчик: «делай следующий урок js». Тема по плану: `if`, `else`.

Файл: `lessons/javascript/05-usloviya-1.jsx`. Сборка: `node tools/js5/build.mjs`. Канон — `canon/javascript/canon-v1.jsx`.

Облик — как уроки 1–4: редактор `script.js`, «Память», консоль и «Расчёт»; страницы нет (до DOM). **Новое — выполнение с ветками**: строка `if` получает метку `true` или `false` (ответ условия, «Расчёт» показывает, как он получился), строки пропущенной ветки гаснут и зачёркиваются, выполнение перескакивает в нужный блок.

Исходник — `tools/js5/`:
- `j5.src.jsx` — META, тексты `C` на трёх языках;
- `j5-engine.jsx` — движок урока 4, но скрипт разбирается целиком: `if (…) { … } else { … }`, блоки через несколько строк, условие — любое значение (по правилам JS); шаги выполнения `steps` (строка, «Память», ответ условия, пропущенные строки); ошибки как в Chrome (`if coins > 100 {` — «Unexpected identifier 'coins'», нет `)` — «Unexpected token '{'», нет `}` — «Unexpected end of input», `If` — «Unexpected token '{'»; `if (lives = 0)` ошибки не даёт и кладёт 0 в коробку);
- `j5-screens.jsx` — экраны: показ запусков `RunShow`, `Predict` (и выбор условия), сборка из строк, задание с полем `GapTask`, «какие строки выполнятся», «найди строку», своя дверь;
- `j5.css` — стили.

## Замысел

- **Ситуация.** В игре Коди таинственная дверь: открывается, только если есть ключ. Программа сама выбирает путь.
- **Загадка** (Коди ошибается): «если условие false и else нет, программа останавливается — строки ниже не работают».
- **Разгадка** (экран 11): пропускается только блок, строка после `}` работает всегда.

**После урока ученик:**
- пишет `if (условие) { … }` и `else { … }`, понимает блок в фигурных скобках;
- считает условие (сравнение, `===`, коробка с true / false) и предсказывает, какая ветка сработает;
- знает, что работает одна ветка из двух, а строки после блока — всегда;
- находит ошибки: условие без скобок, `If`, `=` вместо `===` в условии.
