Курс: Dasturlash kursi
Модуль: HTML
Промпты проверки заданий компилятора (14.11.2026). Задания и примеры — docs/kompilyator-amaliy-html.txt.

======================================================================
1. НАЗВАНИЕ УРОКА: Amaliy ish. HTML hujjatining tuzilishi
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <!DOCTYPE html> at the start of the code.
Use <html>, <head> and <body>.
Use <title> inside <head>, with some text.
Write some text inside <body>.
Text content does not matter.


======================================================================
2. НАЗВАНИЕ УРОКА: Amaliy ish. Sarlavhalar va matn
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <h1>.
Use <h2>.
Use <p>.
Use <b> and <i> inside the text.
Text content and the number of tags do not matter.


======================================================================
3. НАЗВАНИЕ УРОКА: Amaliy ish. Ro'yxatlar
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use one of the heading tags <h1> to <h6>.
Use <ul> and <ol>.
Use <li> inside the lists; every <li> must be inside <ul> or <ol>.
Text content and the number of tags do not matter.


======================================================================
4. НАЗВАНИЕ УРОКА: Amaliy ish. Havolalar va atributlar
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use one of the heading tags <h1> to <h6>.
Use the <a> tag.
Every <a> must have a filled href attribute.
Every <a> must have text between <a> and </a>.
The addresses, texts and the number of tags do not matter; the pages do not have to exist.


======================================================================
5. НАЗВАНИЕ УРОКА: Amaliy ish. Rasmlar
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use the <img> tag.
Every <img> must have a filled src attribute.
Every <img> must have a filled alt attribute.
Use <p>.
<img> has no closing tag; the images do not have to load.
Text content and the number of tags do not matter.


======================================================================
6. НАЗВАНИЕ УРОКА: Amaliy ish. Formalar, 1-qism: ma'lumot kiritish
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <form>.
Use <input> with type text, number and password.
Every <input> must have a filled placeholder attribute.
Use <label>.
All <input> tags must be inside <form>.
Text content and the number of tags do not matter.


======================================================================
7. НАЗВАНИЕ УРОКА: Amaliy ish. Formalar, 2-qism: tanlash va yuborish
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <form>.
Use <select> with <option> tags inside it.
Use <textarea>.
Use <button> with some text.
<select>, <textarea> and <button> must be inside <form>.
Text content and the number of tags do not matter.


======================================================================
8. НАЗВАНИЕ УРОКА: Amaliy ish. Haqiqiy sayt tuzilishi
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <header>, <nav>, <main> and <footer>.
Use a heading tag inside <header>.
Use <a> tags with a filled href inside <nav>.
Use <section> tags inside <main>.
Text content and the number of tags do not matter.


======================================================================
9. НАЗВАНИЕ УРОКА: Yakuniy HTML loyiha
ПРОМПТ ДЛЯ ПРОВЕРКИ:
Use <title> inside <head>.
Use <header>, <nav>, <main> and <footer>.
Use <p>, a list (<ul> or <ol>) and <img> with src and alt.
Use <form> with <input> and <button>.
Text content and the number of tags do not matter.
