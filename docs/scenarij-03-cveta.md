## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает: правило `селектор { свойство: значение; }`, `style` в `head`, селекторы тег / `.class` / `#id`, цвет по имени (уроки 1–2).
- **После урока ученик сможет:**
  1. записать цвет названием: `red`, `blue`, `green`; `light…` — светлее, `dark…` — темнее;
  2. переписать точный цвет из палитры hex-кодом: «#» и шесть знаков (цифры и буквы A–F);
  3. записать цвет через `rgb()`: три луча — красный, зелёный, синий; 0 — выключен, 255 — на полную; красный и зелёный дают жёлтый;
  4. найти и починить поломку: нет «#», пять знаков, опечатка в названии.
- **Не забегаем:** hsl (только назван в выводе), прозрачность, `background-image` (урок 4 «Фон»).
- **Новые слова (draft):** `hex kod`, `palitra`, `nur` (луч света), `panjara belgisi` (решётка).

## Особые правила урока

- **Честный браузер.** Принимает ли браузер цвет — решает сам Chrome (`CSS.supports`): `FA4F28` без «#», `#FA4F2`, `gren` не красят. Один ли это цвет (`#fa4f28` и `#FA4F28`) — тоже браузер (canvas).
- **Помощь видна сразу:** палитра с кодами (hex), полосы «лучей» (rgb), сравнение «логотип — заголовок» (s1, s5, s11, s12, s15).
- В речи hex, rgb, имена свойств и цветов — по-английски (правка речи в `build.mjs`).
