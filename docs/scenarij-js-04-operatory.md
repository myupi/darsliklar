# Сценарий: курс JavaScript, урок 4 «Операторы»

26.11.2026. Заказчик: «делай следующий урок js». Тема по плану: `+ - * /`, `> <`, `===`.

Файл: `lessons/javascript/04-operatory.jsx`. Сборка: `node tools/js4/build.mjs`. Канон — `canon/javascript/canon-v1.jsx`.

Облик — как уроки 1–3: редактор `script.js`, «Память» (коробки по типу) и консоль; страницы нет (до DOM). **Новое — полоса «Расчёт» (Hisob) под кодом**: главное выражение строки считается по шагам в порядке JavaScript: имена заменяются значениями из «Памяти», потом действие за действием — `score > 100 → 120 > 100 → true`, `2 + 3 * 4 → 2 + 12 → 14`.

Исходник — `tools/js4/`:
- `j4.src.jsx` — META, тексты `C` на трёх языках;
- `j4-engine.jsx` — движок урока 3 + порядок действий (`* / %` раньше `+ -`, скобки первыми), сравнения `> < >= <=` и `=== !== == !=`, присваивание внутри выражения, `x` и `×` вместо `*` — честные ошибки; `jsCalc` — шаги расчёта, `JsCalc` — полоса «Расчёт»;
- `j4-screens.jsx` — экраны (`Predict` и `StepShow` урока 3 + полоса «Расчёт»);
- `j4.css` — стили.

## Замысел

- **Ситуация.** В игре Коди открылся магазин: монеты тратятся, нужно сравнивать, хватит ли на покупку, считать урон по боссу.
- **Загадка** (Коди ошибается): «2 плюс 3 умножить на 4 — это 20».
- **Разгадка:** умножение раньше сложения — 14; 20 получится только со скобками.

**После урока ученик:**
- считает с `+ - * /` (умножение — звёздочка, деление — косая черта) и с переменными;
- сравнивает `>` и `<`, получает true / false;
- проверяет равенство `===` и отличает его от `=` («положи»); `"5" === 5` — false;
- знает порядок действий и меняет его скобками.
