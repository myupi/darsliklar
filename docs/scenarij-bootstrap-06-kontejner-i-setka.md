# Сценарий: модуль Bootstrap, урок 6 «Контейнер и сетка» (20.11.2026)

Файл урока: `lessons/bootstrap/06-kontejner-i-setka.jsx`, сборка `node tools/bs6/build.mjs`. Облик «Редактор», канон —
`canon/bootstrap/canon-v1.jsx`. Основа кода — урок 5 (`tools/bs5/`): честная страница с настоящим `bootstrap.min.css`,
экран заданной ширины (`vw`), похожий сайт, курсор показов, задания с полем раундами, сборка по порядку.

Сверено с getbootstrap.com/docs/6.0 (Layout → Breakpoints, Containers, Grid) и CSS (20.11.2026):
- `container` — по центру, max-width 540 / 720 / 960 / 1200 / 1440 px (в таблице сайта для xl — 1140, в CSS — 1200; честная
  страница берёт CSS); `container-fluid` — всегда 100%;
- `row` — flex-ряд с переносом; `col` — равные колонки; `col-1…12` — доля из 12 (`col-6` — 50%); `col-auto`;
- адаптивные классы **через двоеточие**: `sm:col-4`, `md:col-4`, `lg:col-4` — с ширины экрана sm 576, md 768, lg 1024,
  xl 1280, 2xl 1536 px (`@media (width>=768px)`); имена версии 5 (`col-md-4`) в шестой не работают — одной фразой;
- пример сайта: `<div class="container text-center"><div class="row"><div class="col">Column</div>…`.

## Что ученик уже знает

Уроки 1–5 (сайт, копирование, `d-flex`, `gap`, `flex-wrap`, экран телефона 360 px, карточки `card card-body`), CSS 16
«Адаптивность» (`@media (min-width)`, ширина экрана).

## Учебные результаты

1. ограничить и выровнять содержимое страницы по центру (`container`);
2. разделить ряд на колонки (`row`, `col`, `col-N` — доля из 12);
3. сделать, чтобы на телефоне колонки шли друг под другом, а с планшета — в ряд (`md:col-4`);
4. найти это на сайте: Layout → Containers, Grid, Breakpoints.

## Затруднения

- «Для телефона и ноутбука нужны два разных сайта» — загадка, разгадка: один код `md:col-4`.
- `col` без `row` — колонки не встают в ряд (t1, t6).
- Сумма больше 12 — колонка уходит на новую строку (t6).
- `col-md-4` (версия 5), `md-col-4` — нет такого класса (t3, q1).

## Образ и сюжет

Главная страница кружка: три блока «Robotlar», «Jadval», «Aloqa». На ноутбуке они растянуты от края до края и стоят
друг под другом. Ученик ставит контейнер, делит ряд на колонки и делает, чтобы на телефоне колонки шли столбиком.
Загадка (Коди ошибается, без имён): «для телефона и для ноутбука нужно делать два разных сайта». Разгадка: одна строка
`md:col-4` — и сайт сам перестраивается.
