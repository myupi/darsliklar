**Замысел.** При обновлении сайта кафе Коди стёрся CSS: страницы чёрно-белые, вкладки погасли. Ученик оформляет пять страниц и сам пишет CSS; браузер честный — стили применяет сам (страница в рамке без скриптов).

| # | Слайд | Что делает ученик | Ответ | Ветки (своя причина) |
|---|---|---|---|---|
| 1 | крючок | «Обновить» — стили пропали, вкладки гаснут | — | — |
| 2 | т1 Меню | заменить цвет в готовом правиле: заголовок оранжевый | `h1 { color: orange; }` | не тот цвет; русские буквы; нет «:», опечатка в свойстве (с похожим); доп.: абзацы `green` |
| 3 | т2 Напитки | вписать свойство и значение в пустое правило `p { }` | `color: green;` | пусто; не зелёный; доп.: заголовок `purple` |
| 4 | т3 Десерты | правило целиком: фон всей страницы | `body { background-color: pink; }` | нет скобки, не тот селектор; доп.: абзацы `brown` |
| 5 | т4 Контакты | найти и починить две поломки урока | `color: purple` вместо `color = purple`; `;` после `gray` | «=» → «:», нет «;» между свойствами; доп.: `color navy` без «:» |
| 6 | т5 Моё кафе | своя страница: цвет h1, цвет p, фон body (условия видны и загораются) | любые цвета | нет правила для h1 / p / body; заголовок цвета фона |
| 7 | вывод | все вкладки горят, своя страница и её код, умения, дальше — «Селекторы» | — | — |

Помощь на каждом задании: 1 — направление, 2 — правило словами (свойство, значение), 3 — образец под кодом с другим содержимым; со второй неудачи подряд ступень открывается сама; после образца — дополнительная задача.
