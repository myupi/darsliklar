## Учебный замысел

Тема по плану заказчика: вся формула, свой сайт. Урок — повторение всего модуля одним сайтом.

После урока ученик:

- переводит письмо клиента в семь строк промпта (Nima? Nega? Kim uchun? Ichida nima? Ko'rinishi? Qanday ishlaydi? Qoidalar?);
- знает, что даёт сайту каждая строка и что ИИ угадает, если строку пропустить;
- проверяет результат и улучшает его вторым промптом с «qolganini o'zgartirma»;
- делает свой сайт по всей формуле и улучшает его.

**Загадка.** Школа просит сайт фестиваля роботов. Коди пишет одну строку «festival sayti»: «ИИ умный, остальное сделает сам». Выходит чужой фестиваль: ни роботов, ни записи, цвета не школьные, везде «Taxmin». Коди думает, что главную работу делает ИИ, а человеку остаётся нажать кнопку.

**Разгадка.** Главную работу делает человек: понимает клиента, пишет точно, проверяет и улучшает. ИИ — помощник.

## Станции

Станция N показывает сайт так, как в уроке N модуля: строки дальше ещё не написаны, метка — только у новой строки. Строки прежних станций — ответы ученика (если экран пропущен — образцы `FEST`). Заказ — короткая цитата из письма клиента над полем; ученик переводит её в строку формулы.

Проверки — как в уроках модуля:

| Станция | Что нужно |
|---|---|
| st1 | фестиваль и роботы |
| st2, st5 | выбор: запись; современный, синий и белый |
| st3 | не «для всех», есть возраст, есть родители |
| st4 | расписание, фото, контакты |
| st6 | при наведении, кнопка, растёт (не «живо») |
| st7 | номер клиента (последние девять цифр), без окна и скидки |
| st8 | блок вопросов и ответов + «qolganini o'zgartirma» |
| own | семь строк, как в уроке 6 |
| ownfix | точная правка + «qolganini o'zgartirma» |

После второй ошибки подряд открывается следующая ступень подсказки, на третьей — образец.
