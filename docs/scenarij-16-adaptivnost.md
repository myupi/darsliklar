  - **настоящий `@media`**: `withBase` разбирает блок, условие проверяет сам браузер (`matchMedia`, `mqOf`).

  - **блок `@media` в редакторе** (`ruleLines`, `mqParts`): условие своими цветами, поле ввода может стоять прямо в условии.

## Паспорт

- **Ученик:** 11–14 лет, проходит сам, чаще с телефона. Уже знает всё основное CSS: правило, селекторы, размеры (px, %), Box Model, display, Flexbox, позиционирование, hover, transform, transition, анимации (уроки 1–15).
- **После урока ученик сможет:**
  1. выбрать px (всегда одинаково) или % (от ширины окна); растянуть блок на всю ширину: `width: 100%`;
  2. написать `@media (max-width: 600px) { … }` — правила только для узких окон: карточки столбиком, `display: none`;
  3. решить, сработает ли `@media` при данной ширине окна (граница включается);
  4. найти поломку: условие без скобок, число без px, `min-width` вместо `max-width`, `@media` выше обычных правил.
- **Не забегаем:** несколько условий (`and`), em/rem, vw/vh. Тег `meta viewport` — только в артефакте.
- **Новые слова (черновые):** `moslashuvchan sayt` (адаптивный сайт), `foiz` (%), `shart` (условие), `chegara` (граница), `oyna kengligi` (ширина окна), `uxlaydi` (правило «спит»).

## Особые правила урока

- **Честный браузер.**
  - Проценты, перенос строк, прокрутку вбок, `display` и порядок правил считает сам браузер.
  - Условие `@media` проверяет `matchMedia`.
  - Ширина окна — ширина страницы, а не экрана ученика.
- **Телефон:**
  - с открытой панелью подсказки или ошибки на экранах «впиши» и w1 окно браузера ниже, а до 799 px высотой прячется вместе с переключателем ширины;
  - после «Попробовать ещё» всё возвращается.
- В речи названия свойств и значений — по-английски (правка речи в `build.mjs`: `media`, `max-width`, `min-width`).
