- **Ученик уже знает** (уроки 1–2):

  - `h1–h6`, `p`, `b`, `i`;
  - переносы строк в коде не делают абзацев;
  - закрывающий тег набирается кнопками.
- **Ещё не знает:** атрибуты (урок 4) — в уроке их нет.
- **Результаты.** После урока ученик сможет:

  2. выбрать `ul` или `ol` по смыслу: важен ли порядок;
  3. не писать номера руками — их ставит и пересчитывает браузер;

- **Новые понятия и показ:**
  - `li` — пункт: нажимаешь пункт на странице, светится его строка кода;
  - `ul` — коробка всего списка, она ставит точки;
  - `ol` — список с номерами: тот же список, сменили тег — появились номера.
- **Типичные затруднения → где в уроке:**
  - «перенос строки — это пункт» → s6;
  - номера руками → s8, s12;
  - `ul` или `ol` → s7, s9, s14;
  - незакрытый список → s10, s11;
  - `li` вне списка → s12;
  - запись строки `li` → s4, s13.
- **Ситуация.** Коди пишет гайд по игре «Пиксельный остров», игроки (Сардор, Мадина, Азиз) присылают жалобы. Ученик — редактор гайда: каждое задание закрывает чью-то жалобу.
- **Главная механика.** Код гайда и живая страница рядом; жалобы игроков ведут к конкретной поломке.
- **Артефакт:** свой раздел гайда `{ type: 'html-page', topic, title, list, items, html }`.
- **Система слов:** `ul` — список с точками; `ol` — список с номерами; `li` — пункт; «закрыть список» — `</ul>` / `</ol>`.

## Дуга
Крючок (найти третий шаг в абзаце, потом то же со списком с номерами) → план → **ul и li:**
- показ: пункт ↔ строка кода;
- повтор: собрать `li`;
- сам: разрезать пункт по запятым;
- прогноз: переносы не делают пунктов.

→ **ol:**
- показ: пара `ul`→`ol`;
- повтор: вставить шаг, номера пересчитываются;
- сам: `ul` или `ol` с экспериментом «перемешай».

→ **закрыть список:** найти место для `</ul>` → набрать `</ol>` самому.

→ **перенос:** детектив по трём жалобам → написать строку `li` целиком.

→ свой раздел → сохранить → итог.

## Анимации (у каждой функция)
- **s1:** абзац схлопывается в список, номера появляются по очереди — порядок.
- **s3:** пункт и его строка подсвечиваются вместе — связь.
- **s4:** деталь «въезжает» в строку — запись.
- **s5:** на месте запятой «разрез», новый пункт въезжает — изменение.
- **s6:** строки склеиваются в одну, потом каждая получает точку — правда браузера.
- **s8:** новый шаг въезжает, номера ниже вспыхивают — пересчёт.
- **s9:** пункты меняются местами на глазах — эксперимент «перемешай».
- **s10, s11:** раздел, «съеденный» списком, выезжает обратно влево — результат.
- **Reduced motion:** всё сразу, без движения.

## Особые правила урока
- Новые теги:
  - цвет: `ul`, `ol`, `li` — один `#2F6FB0` на семейство (как h1–h6), зелёный тегам не даём;
  - произношение: RU «ю-эль / о-эль / эль-ай», UZ «yu-el / o-el / el-ay», EN «U L / O L / L I».
- Превью честное:
  - `h2` и `p` внутри незакрытого `ul` рисуются со сдвигом, без точки;
  - `li` вне списка — с точкой, но без отступа;
  - номера `ol` ставит браузер.
- Жалобы игроков — короткие печатные карточки (имя + строка), не новые герои; Коди озвучивает суть.
