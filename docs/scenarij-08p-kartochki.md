# Курс CSS · Практика 8 · «Магазин игр Коди» (к уроку 8 «Красивые карточки»)

Файл: `lessons/css/08p-kartochki.jsx` · данные `tools/cssp/p08.jsx` · сборка `node tools/cssp/build.mjs 08` (каркас cssp) · автопроверка `tools/qa/lesson-team/scenarios/css-08p-kartochki.qa.mjs` (`node tools/cssp/mkqa.mjs 08`).

**Замысел.** При обновлении сайта магазина игр стёрся CSS — карточки игр стали плоскими сиреневыми прямоугольниками; ученик сам возвращает им скругление, тень и полосу, а пятую карточку — своей игры — оформляет по-своему.

Стили сайта по умолчанию (не видны ученику): сиреневый фон и отступы карточек, баннер.

| # | Слайд (вкладка) | Что делает ученик | Ответ | Поломки и разбор |
|---|---|---|---|---|
| 1 | Крючок «Новинки» | видит красивые карточки, жмёт «Обновить» — стили пропали, вкладки погасли | — | — |
| 2 | Т1 «Новинки» — заменить значение | скругляет углы карточек на 16px (`.karta { border-radius: 0px; }`) | `16px` | 0px — «углы острые»; другое число — «нужно шестнадцать»; без px — общая причина. Ещё разок: баннер на 24px |
| 3 | Т2 «Спорт» — вписать в правило | даёт карточкам тень только снизу (готово: `border-radius: 16px`) | `box-shadow: 0px 6px 12px gray;` | первое число не ноль — «тень ушла вбок»; второе ≤ 0 — «не вниз»; нет тени. Ещё разок: тень баннеру |
| 4 | Т3 «Хиты» — правило целиком | отмечает только хит оранжевой полосой слева (HTML-справка: `id="xit"`) | `#xit { border-left: 6px solid orange; }` | `.karta` — «полоса у всех»; `border` — «со всех сторон»; без вида линии; не orange. Ещё разок: линия под h1 (`border-bottom`) |
| 5 | Т4 «Скидки» — починить | две поломки урока | `border-radius: 12px;` и `box-shadow: 0px 6px 12px gray;` | `border-radius: 12` (нет px), тень с запятыми; числа менять нельзя. Ещё разок: `border-left: 6px orange` без вида линии → `solid` |
| 6 | Т5 «Моя игра» — своя карточка | углы, тень, полоса с одной стороны — значения любые; условия «готово» загораются | например `.karta { border-radius: 16px; box-shadow: 0px 6px 12px silver; border-left: 6px solid purple; }` | нет скругления / тени / полосы; полоса без вида; рамка со всех сторон |
