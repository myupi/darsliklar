## Паспорт

- lessonId `html-08p-struktura-sajta`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона. Последняя практика курса (урок 9 — финальный проект, без практики).
- Материал урока 8: `header` — верх сайта, `nav` — меню, `main` — главная часть (одна на странице), `section` — раздел внутри `main` (сколько угодно), `footer` — низ; порядок header → main → footer; вид страницы эти теги не меняют — части видны рамками «Инспектора»; `head` ≠ `header` (загадка урока: верх, обёрнутый в head, рамки не получает).
- Не забегаем: CSS, `article`, `aside`, `div`, ARIA.
- Смесь:
  - с уроком 4 — меню `nav` со ссылкой `a href`;
  - с уроками 1–2 — `head` против `header`, заголовки `h1` и `h2`, абзацы.
- Что ученик напишет сам:
  1. имя тега `main` (в дополнительной задаче — `footer`);
  2. строку меню `<nav><a href="index.html">…</a></nav>`;
  3. раздел `section` с `h2` и абзацем внутри `main`;
  4. найдёт верх в `head` вместо `header` (в дополнительной задаче — опечатку `foter`);
  5. свой сайт: `header` (h1, nav со ссылкой), `main` (section с h2 и p), `footer` — по порядку.
- Лесенка письма: т1 значение (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своё по схеме (большой редактор).
- Операция: сайт школы Коди — главная, новости, кружки, контакты; Коди разложил страницы на части, а при сохранении части перепутались, рамки «Инспектора» пропали. Ученик чинит страницы по одной, пятая — его сайт.
- **Карта — вкладки браузера**, как в 01p–07p: Bosh sahifa, Yangiliklar, To'garaklar, Aloqa, Mening saytim.
- **«Инспектор» включён всегда:** пунктирные рамки частей с именем тега в цвете урока 8 (header — оранжевый, nav — фиолетовый, main — бирюзовый, section — янтарный, footer — малиновый), значок «Inspektor» на окне.
- Артефакт: `{ type: 'html-page', title, heading, sections, footer, html }` — свой сайт из т5 (тексты и адреса через `escHtml`).
- Типичные ошибки набора:
  - `section`, `head`, опечатка `mian` вместо `main`;
  - ссылка без `nav`, `nav` без ссылки, `a` без `href`, не тот файл, не то слово ссылки;
  - `h2` и `p` без `section`, второй `main`, раздел без `h2` или без абзаца, не закрыт `section`;
  - `head` вместо `header`, опечатка `foter`;
  - нет `header`, `h1` вне `header`, нет `nav`, нет `main`, нет `section`, нет `footer`, части не по порядку, текст вне частей.

## Особые правила

- Код ученика не исполняется; страница рисуется React как текст; `<`, `&` — как текст и в превью, и в артефакте.
- Честно, как в уроке 8: части вид страницы не меняют; `head` внутри `body` и незнакомый тег — рамки нет, текст на месте; «<>» без имени тега браузер показывает как текст.
- Телефон: на 360 × 640 в задании 1 и на выводе окно браузера ниже, на высоком телефоне в задании 3 — не выше 16 : 7,5; страница в окне подгоняется шрифтом (на маленьком телефоне — до 0,52 от обычного).
