## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает из уроков 1–3: каркас страницы, теги, заголовки, абзацы, b, i, списки; браузер читает сверху вниз.
- **После урока ученик сможет:**
  1. сделать ссылку: тег `a` и атрибут `href` с именем файла;
  2. разобрать атрибут: имя, «=», значение в кавычках; атрибут только в открывающем теге;
  3. найти и починить ссылку: нет `href` (простой текст), опечатка в имени файла («Файл не найден»), нет `</a>` (ссылкой стал хвост);
  4. сделать ссылку на свою страницу.
- **Не забегаем:** абсолютные адреса (https://), `target`, картинки (урок 5).
- **Новые слова (draft):** `qiymat` (значение), `manzil` (адрес), `qo'shtirnoq` (кавычки).

## Особые правила урока

- Честный браузер: ссылка с href — синяя и подчёркнутая (так рисует любой браузер без CSS — это содержимое страницы, не цвет интерфейса), по нажатию открывает файл, адрес меняется, стрелка «назад» возвращает; a без href — простой текст; нет файла — «Файл не найден»; без `</a>` ссылкой становится и текст дальше.
- В речи тег a звучит буквой «A», href — по-английски (правка речи в `build.mjs`).
