# Курс CSS · Практика 10 · «Космический сайт Коди» (к уроку 10 «Flexbox: расположение элементов»)

Файл: `lessons/css/10p-flexbox-osi.jsx` · данные `tools/cssp/p10.jsx` · сборка `node tools/cssp/build.mjs 10` (каркас cssp) · автопроверка `tools/qa/lesson-team/scenarios/css-10p-flexbox-osi.qa.mjs` (`node tools/cssp/mkqa.mjs 10`).

**Замысел.** При обновлении космического сайта стёрся CSS — карточки планет выпали из ряда; ученик расставляет всё Flexbox (flex — родителю `div.javon`, направление, оси), а пятую страницу — свою вселенную — строит сам.

Стили сайта по умолчанию (не видны ученику): полка — светлая коробка с пунктиром (видно родителя), сиреневые карточки с отступами, фон у ссылок меню.
