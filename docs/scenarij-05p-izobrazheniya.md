## Паспорт

- lessonId `html-05p-izobrazheniya`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона.
- Материал урока 5: тег `img` без пары ставит картинку; `src` — имя файла, буква в букву; `alt` — описание словами, его видно, если картинки нет; нет такого файла — значок сломанной картинки и alt; `href` и `</img>` у `img` не работают.
- Смесь:
  - с уроком 2 — абзац `p` под картинкой, своя страница с `h1` и `p`;
  - с уроком 4 — атрибуты: `имя="значение"`, ошибка `href` вместо `src`.
- Что ученик напишет сам:
  1. имя файла в `src`;
  2. строку `<img src="…" alt="…">` целиком;
  3. картинку и абзац под ней;
  4. найдёт `img` с `href` и заменит на `src`;
  5. свою страницу: `h1`, `img` с `src` и `alt`, `p`.
- Лесенка письма: т1 значение (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своё по схеме (большой редактор).
- Операция: сайт зоопарка Коди — страницы животных с фото. При сохранении у картинок пропал `src`: вместо фото на страницах остался только текст alt, вкладки погасли. Ученик чинит страницы по одной, пятая — его страница.
- **Карта — вкладки браузера**, как в 01p–04p: Sher, Fil, Jirafa, Panda, Mening sahifam.
- **Файлы картинок** (список рядом с кодом): `sher.jpg`, `fil.jpg`, `jirafa.jpg`, `panda.jpg`, `toshbaqa.jpg`, `kapalak.jpg` — рисунки животных в SVG.
- Код — часть `body`, как в уроках 2–5. Разбор кода понимает атрибуты: у `img` — `src` и `alt`, у `a` — `href`.
- Артефакт: `{ type: 'html-page', title, heading, text, src, alt, html }` — своя страница из т5 (тексты через `escHtml`).
- Типичные ошибки набора:
  - нет `src` или пустой `src`;
  - нет такого файла (в том числе с большой буквы);
  - не та картинка;
  - `href` вместо `src`;
  - нет `alt` или пустой `alt`;
  - нет кавычек, нет `=`, опечатка в имени атрибута;
  - `</img>`;
  - абзац раньше картинки, нет абзаца;
  - страница без `h1` или без картинки.

## Особые правила

- Код ученика не исполняется; страница рисуется React как текст; `<`, `&` — как текст и в превью, и в артефакте.
- Честный браузер — как в уроке 5: нет `src` — только текст alt; нет файла — значок сломанной картинки и alt; `href` у `img` браузер не замечает. Имя файла сверяется буква в букву: `Sher.jpg` — сломанная картинка.
