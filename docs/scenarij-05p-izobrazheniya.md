## Операция

Выставка рисунков класса: пять рам на стене. В хуке ученик нажимает «Открыть выставку» — подул ветер, картинки выпали из рам. Ученик возвращает их кодом и собирает свою галерею. Рама загорается, когда картинка вернулась.

## Проверка и подсказки

- **Проверка по «Проверить».** Называет одну проблему. Со второй неудачи подряд к ней добавляется ступень подсказки.
- **Фразы проверки:**
  - нет картинки, нет src / пусто;
  - не тот файл;
  - файла нет (с именем);
  - alt поменялся;
  - нет alt / пустой alt;
  - в alt имя файла;
  - в alt «картинка», «фото» и подобное («ничего не говорит о картинке»);
  - href у img;
  - опечатка в имени атрибута (`scr`, `sr` → src);
  - `</img>`;
  - нет кавычек, нет «=».
- **Лампочка — три ступени:** направление → место или правило (в t4 — номер строки, строка подсвечена) → образец с другим содержимым. После образца — дополнительная задача:
  - t1 — собака;
  - t2 — `dgo.jpg` и `cat.png`;
  - t3 — alt для цветка;
  - t4 — `sr` и `</img>`;
  - t5 — ещё картинка `flower.jpg`.
- **Артефакт:** `{ type: 'html-page', title, text, items, images, html }` — галерея из t5.
