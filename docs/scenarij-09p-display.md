# Курс CSS · Практика 9 · «Кинотеатр Коди» (к уроку 9 «Как элементы ведут себя на странице»)

Файл: `lessons/css/09p-display.jsx` · данные `tools/cssp/p09.jsx` · сборка `node tools/cssp/build.mjs 09` (каркас cssp) · автопроверка `tools/qa/lesson-team/scenarios/css-09p-display.qa.mjs` (`node tools/cssp/mkqa.mjs 09`).

**Замысел.** При обновлении сайта кинотеатра стёрся CSS — кнопки меню стали крошечными и разными, надоедливая реклама вылезла; ученик возвращает порядок свойством `display`, а пятую страницу — свой кинотеатр — собирает сам.

Стили сайта по умолчанию (не видны ученику): фон у ссылок и меток (чтобы было видно строчный элемент и блок), яркая реклама, плашка подписки, фон у блюд.

|---|---|---|---|---|
| 1 | Крючок «Афиша» | видит ровное меню без рекламы, жмёт «Обновить» — кнопки разные, реклама видна | — | — |
| 2 | Т1 «Афиша» — заменить значение | прячет рекламу (`.reklama { display: block; }`) | `none` | `hidden` — браузер выбросил значение (общая причина); другое — «нужно слово, которое прячет». Ещё разок: плашка подписки `.xabar` |
| 3 | Т2 «Жанры» — вписать в правило | метки span одной ширины (готово: `.janr { width: 80px; }` — не действует) | `display: inline-block;` | block — «встали столбиком»; inline — «ширина не работает»; none — «пропали». Ещё разок: кнопки сеансов `.vaqt` |
| 4 | Т3 «Буфет» — правило целиком | каждое блюдо на своей строке (HTML-справка: `class="taom"`) | `.taom { display: block; }` | inline-block — «остаются рядом»; none — «пропали». Ещё разок: залы `.zal` |
| 5 | Т4 «Билеты» — починить | две поломки урока | `display: inline-block;` и `display: none;` | `inline block` без чёрточки, `hidden` вместо none. Ещё разок: `.xabar { display: hidden; }` |
| 6 | Т5 «Мой кинотеатр» — своя страница | ссылки — кнопки одной ширины своего цвета, реклама спрятана; условия «готово» загораются | например `a { display: inline-block; width: 80px; background-color: gold; }` и `.reklama { display: none; }` | none / block у ссылок; нет width; нет фона; реклама видна |
| 7 | Вывод | все вкладки горят, своё меню; умения: block, inline-block и width, none, починка; дальше — Flexbox | — | — |
