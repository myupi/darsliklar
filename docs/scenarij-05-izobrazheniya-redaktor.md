## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает из уроков 1–4: каркас страницы, заголовки, абзацы, списки, ссылки; атрибут — имя, «=», значение в кавычках; браузер читает сверху вниз; браузер ищет файл буква в букву.
- **После урока ученик сможет:**
  1. поставить картинку: тег `img` и атрибут `src` с именем файла;
  2. описать картинку атрибутом `alt` и объяснить, зачем он (картинка не открылась, программа чтения вслух);
  3. найти и починить картинку: нет `src` (пусто или только alt), опечатка в имени файла (значок сломанной картинки), `href` вместо `src`; помнить, что у `img` нет закрывающего тега;
  4. поставить картинку на свою страницу и написать ей alt.
- **Не забегаем:** адреса в интернете (https://), размеры `width`/`height`, папки с картинками, CSS.
- **Новые слова (draft):** `manba` (источник), `muqobil matn` (альтернативный текст), `buzilgan rasm belgisi` (значок сломанной картинки).

## Особые правила урока

- Честный браузер: есть такой файл — картинка; нет файла — значок сломанной картинки и текст alt (без alt — один значок), как в Chrome; нет src (или вместо него href) — ничего, есть alt — только его текст; `img` строчный — несколько картинок встают в строку, в порядке строк кода.
- «Фото» — плоские рисунки в цветах облика (плов, кот, мяч, цветок), файлы видны в панели «Файлы» с миниатюрами.
- Код картинки разбит на куски (`<img`, каждый атрибут): на телефоне длинная строка переносится между атрибутами, а не обрезается.
- В речи img и src — по буквам («I M G», «S R C»), alt — по-английски (правка речи в `build.mjs`).
