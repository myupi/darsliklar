## Паспорт

- lessonId `html-07p-formy-vybor`; модуль `html-m1-osnovy`; 11–14 лет, сами, чаще с телефона.
- Материал урока 7: `select` — выпадающий список, каждый пункт — в своём `option`; текст внутри `select` без `option` в список не попадает (загадка урока); `textarea` — большое поле, у него есть закрывающий тег, без `</textarea>` весь код дальше становится текстом в поле; `button` — кнопка, надпись между тегами, кнопка закрывается.
- Не забегаем: `name`, `value`, `action`, `method`, `selected`, `type` у кнопки.
- Смесь:
  - с уроком 6 — `form`, `label`, поле `input` с `placeholder`;
  - с уроком 3 — `li` не годится для пункта `select` (типичная путаница).
- Что ученик напишет сам:
  1. имя тега `option` у пункта списка;
  2. строку кнопки `<button>…</button>`;
  3. `select` с тремя `option`;
  4. найдёт слово в `select` без `option` и обернёт его; в дополнительной задаче — закроет `textarea`;
  5. свою анкету: `h1`, `form`, `select` (хотя бы два `option`), `textarea`, `button`.
- Лесенка письма: т1 значение (поле в строке) → т2 строка → т3 блок → т4 найти строку и исправить → т5 своё по схеме (большой редактор).
- Операция: сайт летнего лагеря Коди — смена, запись, спорт, отзывы, и на каждой странице анкета. При сохранении анкеты сломались. Ученик чинит их по одной, пятая — его анкета.
- **Карта — вкладки браузера**, как в 01p–06p: Smena, Yozilish, Sport, Fikrlar, Mening anketam.
- Код — часть `body` (в заданиях 2–4 — часть `form`). Разбор кода понимает: `select` с `option`, `textarea` с `placeholder` и закрывающим тегом, `button` с надписью; `label` может держать любое поле.
- Артефакт: `{ type: 'html-page', title, heading, options, button, html }` — своя анкета из т5 (тексты через `escHtml`).
- Типичные ошибки набора:
  - `li` или `p` вместо `option`, `select` вместо `option`, опечатка `opton`;
  - слово в `select` без `option`, `option` вне `select`, не закрыт `select` или `option`;
  - `<input type="button">` вместо `button`, не закрыт `button`, пустая кнопка, не та надпись;
  - не закрыт `textarea` (код дальше — текст в поле);
  - поля без `form`, нет списка, один пункт, нет большого поля, нет кнопки, анкета без `h1`.
