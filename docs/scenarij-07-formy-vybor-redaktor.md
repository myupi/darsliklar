## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает из уроков 1–6: страница, тексты, списки ul/ol/li, ссылки, картинки; поле input, type, placeholder, label, form; у input нет закрывающего тега.
- **После урока ученик сможет:**
  1. сделать выпадающий список `select` с пунктами `option`;
  2. поставить большое поле `textarea` и помнить, что у него есть закрывающий тег (без него следующий код становится текстом в поле);
  3. поставить кнопку `button` с надписью между тегами и объяснить, что кнопка в `form` отправляет анкету;
  4. найти и починить: слово в `select` без `option`, `li` вместо `option`, незакрытый `textarea`, опечатку в имени тега.
- **Не забегаем:** `name`, `value`, `action`, `method`, `selected`, `type` у кнопки, сервер и обработка ответов (только честное «сервера нет — страница заново»).
- **Новые слова (draft):** `ochiladigan ro'yxat` (выпадающий список), `variant` (пункт), `katta matn maydoni` (большое поле), `server`.

## Особые правила урока

- Честный браузер, как Chrome по умолчанию: select — поле со стрелкой, в нём первый или выбранный пункт, раскрытый список (в Chrome он всплывает над страницей; здесь — панель под полем, чтобы не уходил за окно); текст без option в список не попадает; textarea — моноширинный шрифт, перенос, уголок растягивания; без `</textarea>` всё дальше — текст в поле; button — серая кнопка; кнопка в form отправляет, а без сервера страница открывается заново и поля пустеют.
- Код списков многострочный (select, option с отступом); длинные строки на телефоне переносятся между кусками.
- В речи select, option, textarea, button, form, input, placeholder — по-английски (правка речи в `build.mjs`).
