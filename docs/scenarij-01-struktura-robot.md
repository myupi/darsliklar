## Особые правила урока

- Слои Bob:
  - класс `rb-html` — детали; без него Bob исчезает, остаётся подставка;
  - `rb-css` — раскраска групп `data-paint`, цвета генерирует сборка;
  - `rb-js` — анимации: рука, глаза, антенна, курсор, кнопки ответа;
  - при «меньше движения» анимаций нет.
- Цвета слоёв на переключателях: HTML — `#586A83` (цвет тега html), CSS — `#227882`, JavaScript — `#8A5A3C`.
- `RFIG_BUST` — крупный план робота (r2, финал): экран Bob читается.

Все реплики на трёх языках — в `C` исходника `tools/robot/robot.src.jsx`.

## Правки по замечаниям заказчика (17.10.2026)

- **r1.** После каждого слоя Коди называет следующий («Теперь включи «Вид» — это CSS»).
- **r2.** Пока Коди говорит «на вкладке — название», обведена вкладка; «в окне — содержимое страницы», обведено окно; затем — код. Вместо «сама игра» — «содержимое страницы». Имя робота по-русски — кириллицей и в падеже («на экране у Боба»), чтобы не звучало обращением к ученику.
- **m.** Карточка — «Твоя страница — на экране Боба».
- **s2.** Сначала Коди сам показывает три части тега по очереди. Затем спрашивает «Где начало тега?» и т. п., и ученик нажимает. Строка в одну линию и на телефоне. Вкладка показана в настоящем окне браузера с подписью «← вкладка». Нет «красных» пояснений.
- **s3.** После каждой части Коди говорит, что открыть дальше: любое отделение → другое → «Нажми на title». Итог по частям: пока он называет html, head, body, часть светится в коробке, коде и браузере.
- **s6.** Задание объяснено: «В код попадёт новое слово — угадай, где оно появится». Вопрос каждого раунда звучит вслух.
- **s7.** Рука показывает перетаскивание детали на коробку. После сборки «Код» светится оранжевым, пока его не открыли.
- **s8.** Рука показывает первую пару, `<head>` → `</head>`. Код вне пары не тускнеет.
- **s9.** Рука показывает «title → head». Жёлтая плашка подсказки убрана: ступени лесенки встают в строку задания, а правило — спокойная карточка.
- **s12.** Коди читает заказ вслух.
- **s13.** Строки перетаскиваются из лотка на места и меняются местами. Первый ход показывает рука.
- **s14.** Финал без перегруза: крупный Боб со страницей ученика, достижения, следующий урок.
- **Поля ввода во всех уроках** растут по тексту: сначала в ширину, у края строки — перенос и рост в высоту; теги рядом не сжимаются.
- **s7, рука.** Деталь переносится в код — к строке `</html>`, где при перетаскивании встаёт место «сюда: внутрь html».
