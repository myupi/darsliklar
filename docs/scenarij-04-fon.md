## Паспорт

- **Ученик** 11–14 лет, сам, чаще с телефона. Знает: правило, `style` в `head`, селекторы тег / `.class` / `#id`, цвета именем, hex, rgb, hsl (уроки 1–3); из курса HTML — `img src`.
- **После урока ученик сможет:**
  1. дать фон любому элементу: `background-color` для `body`, `h1`, `p`;
  2. поставить картинку на фон: `background-image: url("файл");`;
  3. управлять картинкой: по умолчанию маленькая повторяется плиткой, `background-repeat: no-repeat` — одна, `background-size: cover` — на весь фон;
  4. найти и починить поломку фона: нет `url( )`, опечатка в имени файла, `no repeat` с пробелом; знать, что запасной `background-color` виден, когда картинки нет.
- **Не забегаем:** `background-position` словами, сокращённое свойство `background`, градиенты, прозрачность, отступы (`padding` — урок 7).
- **Новые слова (draft):** `fon rasmi` (картинка фона), `kafel kabi` (плиткой), `takrorlanadi`, `zaxira rang` (запасной цвет), `fayl nomi`, `chiziqcha` (дефис).

## Особые правила урока

- **Честный браузер.** Верная ли запись — решает Chrome (`CSS.supports`): `"maydon.jpg"` без url и `no repeat` с пробелом не принимаются. Картинки — файлы урока (`FILES` в `c4-screens.jsx`: maydon.jpg, osmon.jpg, futbol.png, yulduz.png — свои SVG); имени нет среди файлов — картинки нет, виден цвет фона. Маленькая картинка без `no-repeat` повторяется плиткой; фон body — на всё окно; блоки страницы — во всю ширину, как в браузере.
- **Помощь видна сразу:** полоса «Файлы» с картинками и именами (s5, s11, s13, s14), мини-страницы с фоном (s7, s10).
- На телефоне в s14 строки `style` спрятаны, пустые поля узкие; с открытой клавиатурой полоса «Файлы» прячется (как палитра в уроке 1).
- В речи background-color, background-image, background-repeat, background-size, url, no-repeat, cover и имена цветов — по-английски (правка речи в `build.mjs`).
