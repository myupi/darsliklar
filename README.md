# Darsliklar — просмотр интерактивных уроков

Проект, в котором лежат JSX-уроки (один урок — один самодостаточный файл) и в котором их можно сразу открыть и проверить: в рамке телефона, планшета или ноутбука, на любом языке, с журналом всего, что урок делает с платформой.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173

## Где что лежит

```
darsliklar/
├── lessons/                         ← ВСЕ УРОКИ ЗДЕСЬ
│   ├── html/
│   │   ├── _course.js               ← план курса: номера, темы, цвет
│   │   ├── 01-struktura-dokumenta.jsx
│   │   └── 02-zagolovki-i-tekst.jsx …
│   ├── css/
│   │   ├── _course.js
│   │   └── 01-chto-takoe-css.jsx …
│   └── _reference/                  ← эталонные уроки других курсов (для сравнения)
│
├── src/
│   ├── runtime/                     ← эмуляция платформы (@lesson/runtime)
│   ├── player/                      ← плеер: открывает один урок внутри iframe
│   ├── viewer/                      ← интерфейс просмотрщика (каталог, панель, журнал)
│   └── shared/catalog.js            ← сборка каталога из папки lessons/
├── index.html                       ← просмотрщик
└── player.html                      ← страница плеера
```

Работать почти всегда нужно только с папкой `lessons/`.

## Как добавить урок

1. Положить файл в папку курса: `lessons/<курс>/<NN>-<slug>.jsx`.
2. `NN` — номер урока из `_course.js` (01, 02 … 17). По этому номеру урок встаёт на своё место в плане.
3. Всё. Урок сам появится в каталоге с зелёной точкой «готов», перезапуск не нужен.

Точный путь для каждого ещё не созданного урока показан в просмотрщике: кликните по уроку в плане.

## Как добавить курс или тему

- **Новая тема в курсе** — добавить строку в `lessons/<курс>/_course.js`.
- **Новый курс** — создать папку `lessons/<новый-курс>/` и в ней `_course.js` (скопировать формат из `html/_course.js`).

## Что умеет просмотрщик

| | |
|---|---|
| **Экран** | Телефон 390×844, планшет 820×1180, ноутбук 1366×800, во всю область; поворот устройства |
| **Язык** | RU / UZ / EN — уходит в урок пропом `lang` |
| **Ученик** | имя — пропом `studentName` |
| **Голос** | «Браузер» — реплики читает голос браузера; «Тихо» — без звука, но с паузой по длине реплики; «Быстро» — то же, но паузы вшестеро короче (прогнать урок на проверке); «Нет» — голоса нет совсем (проверка, что урок не зависает и печатает реплики) |
| **С экрана** | открыть урок сразу на экране N (дев-пропсы `startAt` / `startScreen`) |
| **Журнал** | каждая реплика (с маркером языка), ожидания `waits_for`, `triggerEvent`, звуки, ошибки, `onFinished` с payload |
| **Проверка контракта** | `onFinished` должен вызываться ровно один раз; падение урока показывается с текстом ошибки, а не белым экраном |

Настройки сохраняются в адресе страницы, поэтому ссылкой можно поделиться.

## Канон курса и бриф

- `docs/brif-uroka.md` — бриф: как устроен урок, контракт с платформой, чек-лист приёмки.
- `canon/html/canon-v1.jsx` — общий канон курса HTML. Каждый урок копирует его дословно сверху.
- Проверить, что канон в уроках не тронут:

```bash
node tools/check-canon.mjs
```

## Что урок получает от просмотрщика

То же, что на платформе:

- пропсы `{ studentName, lang, onFinished }`;
- `import { useAudio, useSfx, useAssets } from '@lesson/runtime'`;
- по брифу урок импортирует только `react` и `@lesson/runtime` (эталоны других курсов используют ещё `framer-motion` и `lucide-react` — просмотрщик их тоже поддерживает);
- шрифты Manrope, Source Serif 4, Nunito, JetBrains Mono, Inter, Fraunces (на платформе их отдаёт LMS).
