# Тренажёр модуля CSS — загрузка в LMS

В LMS загружаются **два файла**:

1. `trenajor_css_v1.jsx` — React-компонент тренажёра. Импортирует только `react`.
2. `savollar_banki_css_v1.json` — банк из 309 вопросов по урокам 1–17 модуля CSS (`block_id: "css"`): 188 с выбором ответа (`single_choice`), 52 «впиши ответ» (`text_input`) и 69 игровых — «собери из кусочков» (`assemble`, 34), «найди ошибку» (`find_error`, 18), «нажми на странице» (`tap_page`, 17).

Оба файла собирает `node tools/trenajor/build.mjs css` — руками их не править.

## Всё как у тренажёра HTML

Контракт, типы вопросов, сохранение ответов и мягкое сравнение строк (`norm`) — **те же, что у тренажёра HTML**: см. `trenajor/html/README.md`.
Если LMS уже принимает тренажёр HTML, для CSS ничего нового не нужно — только другой банк (`block_id: "css"`, `module: "css"`).

Отличия:

- **Миссия «Сайт одевается»** (вместо «Сайт строится»): рядом с полосой прогресса — маленький сайт, у которого все 15 частей уже есть,
  но серые и бледные — как HTML без CSS. Каждый верный ответ оформляет свою часть («+ Menyu qatorda» в отклике), неверный оставляет её серой
  с красной пунктирной рамкой. На итоговом экране нажатие на серую часть показывает тот вопрос, ответ ученика, верный ответ и пояснение.
  Тренажёр считает это сам из `attempt.answers`; какую миссию показать, он узнаёт по полю `module` вопросов.
- Картинка вопроса: в редакторе — файл `style.css` с подсветкой CSS (или HTML с блоком `<style>`), рядом — окно браузера, где страница
  нарисована с этими правилами. Строка `vis` начинается с того же `@htmlvis:`.
- В «впиши ответ» ответ — одно слово кода: свойство (`font-size`), значение (`center`), число с единицей (`20px`), селектор (`.karta`).
  Пробелы внутри не убираются: `20 px` ≠ `20px` (в CSS это и есть ошибка).

## Банк вопросов

- 309 вопросов: уроки 1–16 — по 18 (11 с выбором, 3 «впиши ответ», 2 «собери», 1 «найди ошибку», 1 «нажми на странице»), урок 17 (финальный) — 21 (12, 4, 2, 2, 1). У каждого `lesson` (1–17) и тег `darsNN`.
- **LMS выбирает по блоку** (`block_id: "css"`, 15 случайных). Чтобы ученик получал вопросы только из пройденных уроков, LMS может фильтровать по `lesson`.
- У вопросов с выбором верный ответ стоит на местах A–D поровну (и в каждом уроке тоже).
- Тексты на трёх языках: `uz` (на «Siz»), `ru` (на «ты»), `en`.
- `status: "Approved"` стоит, чтобы LMS могла выбирать вопросы; **методист вопросы ещё не проверял**.

## Проверка

`node tools/trenajor/build.mjs --check css`. Просмотр — в просмотрщике уроков, раздел **«Тренажёр»** → CSS (попытка с эмуляцией LMS и все вопросы
по урокам). Отдельно: `/trainer.html?t=css&lang=uz`. Замер раскладки всех вопросов — `tools/trenajor/sweep-all.js` (как запускать — в его шапке).
