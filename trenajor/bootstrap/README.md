# Тренажёр модуля Bootstrap — загрузка в LMS

В LMS загружаются **два файла**:

1. `trenajor_bootstrap_v1.jsx` — React-компонент тренажёра. Импортирует только `react`.
2. `savollar_banki_bootstrap_v1.json` — банк из 183 вопросов по урокам 1–10 модуля Bootstrap (`block_id: "bootstrap"`): с выбором ответа
   (`single_choice`), «впиши ответ» (`text_input`) и игровые — «собери из кусочков» (`assemble`), «найди ошибку» (`find_error`),
   «нажми на странице» (`tap_page`).

Оба файла собирает `node tools/trenajor/build.mjs bootstrap` — руками их не править.

## Всё как у тренажёра HTML и CSS

Контракт, типы вопросов, сохранение ответов и мягкое сравнение строк (`norm`) — **те же, что у тренажёра HTML**: см. `trenajor/html/README.md`.
Если LMS уже принимает тренажёры HTML и CSS, для Bootstrap ничего нового не нужно — только другой банк (`block_id: "bootstrap"`, `module: "bootstrap"`).

Отличия:

- **Миссия «Сайт одевается»** — как у CSS: 15 серых частей сайта, каждый верный ответ даёт своей части слово Bootstrap («+ Tugma: btn-solid»),
  неверный оставляет её серой с красной пунктирной рамкой. Какую миссию показать, тренажёр узнаёт по полю `module` вопросов.
- **Страница вопроса — на настоящем CSS Bootstrap 6** (6.0.0-alpha.1, тот же файл, что в уроках модуля; светлая тема). CSS лежит внутри
  `trenajor_bootstrap_v1.jsx` строкой — тренажёр ничего не грузит из сети. Поэтому файл тренажёра Bootstrap больше, чем у HTML и CSS.
- Скриптов на странице нет: меню и окно показаны открытыми (как статичные примеры на сайте Bootstrap), у карусели виден первый слайд.
- В «впиши ответ» ответ — одно слово кода: класс (`img-fluid`, `form-control`, `md:col-4`), значение атрибута (`menu`, `dialog`), число.

## Банк вопросов

- Уроки 1–9 — по 18 (11 с выбором, 3 «впиши ответ», 2 «собери», 1 «найди ошибку», 1 «нажми на странице»), урок 10 (финальный) — 21 (12, 4, 2, 2, 1).
  У каждого `lesson` (1–10) и тег `darsNN`.
- **LMS выбирает по блоку** (`block_id: "bootstrap"`, 15 случайных). Чтобы ученик получал вопросы только из пройденных уроков, LMS может фильтровать по `lesson`.
- У вопросов с выбором верный ответ стоит на местах A–D поровну.
- Тексты на трёх языках: `uz` (на «Siz»), `ru` (на «ты»), `en`.
- `status: "Approved"` стоит, чтобы LMS могла выбирать вопросы; **методист вопросы ещё не проверял**.

## Проверка

`node tools/trenajor/build.mjs --check bootstrap`. Просмотр — в просмотрщике уроков, раздел **«Тренажёр»** → Bootstrap (попытка с эмуляцией LMS
и все вопросы по урокам). Отдельно: `/trainer.html?t=bootstrap&lang=uz`.

## Исходники

- Тренажёр — `tools/trenajor/trenajor.jsx` (один на все модули; CSS Bootstrap в него вставляет сборщик), вопросы —
  `tools/trenajor/bootstrap/l01.mjs … l10.mjs`, правила вопросов — `tools/trenajor/bootstrap/FORMAT.md`.
