# Тренажёр модуля «ИИ» — загрузка в LMS

В LMS загружаются **два файла**:

1. `trenajor_ai_v1.jsx` — React-компонент тренажёра. Импортирует только `react`.
2. `savollar_banki_ai_v1.json` — банк из 147 вопросов по урокам 1–8 модуля «ИИ» (`block_id: "ai"`). **Все вопросы — с выбором ответа** (`single_choice`, 4 варианта), как тесты модуля.

Оба файла собирает `node tools/trenajor/build.mjs ai` — руками их не править.

## Всё как у тренажёров HTML и CSS

Контракт и сохранение ответов — **те же, что у тренажёра HTML**: см. `trenajor/html/README.md`.
Если LMS уже принимает тренажёры HTML и CSS, для «ИИ» ничего нового не нужно — только другой банк (`block_id: "ai"`, `module: "ai"`).
Других типов вопросов («впиши», «собери», «найди ошибку», «нажми») в этом банке нет.

Отличия:

- **Миссия «Заказы студии»** (вместо «Сайт строится»): рядом с полосой прогресса — доска из 15 заказов клиентов студии.
  Каждый верный ответ сдаёт заказ — на доске появляется готовый сайт клиента с зелёной галочкой («+ Pitsa kafesi» в отклике),
  неверный — заказ вернулся на доработку (красная рамка, стрелка назад). На итоговом экране нажатие на вернувшийся заказ показывает тот вопрос,
  ответ ученика, верный ответ и пояснение. Тренажёр считает это сам из `attempt.answers`; какую миссию показать, он узнаёт по полю `module` вопросов.
- Картинка вопроса (`vis`, строка начинается с того же `@htmlvis:`, внутри — `{"ai": …}`): поле промпта с цветными метками формулы модуля
  (Nima? Nega? Kim uchun? Ichida nima? Ko'rinishi? Qanday ishlaydi? Qoidalar?), сообщение клиента и сайт, который «собрал ИИ», в окне браузера.
  На ноутбуке промпт и сайт рядом, на телефоне — друг под другом; на маленьком телефоне — переключатель «Prompt / Sayt».

## Банк вопросов

- 147 вопросов: уроки 1–7 — по 18, урок 8 (финальный проект) — 21. У каждого `lesson` (1–8) и тег `darsNN`.
- **LMS выбирает по блоку** (`block_id: "ai"`, 15 случайных). Чтобы ученик получал вопросы только из пройденных уроков, LMS может фильтровать по `lesson`.
- Верный ответ стоит на местах A–D поровну (и в каждом уроке тоже).
- Тексты на трёх языках: `uz` (на «Siz»), `ru` (на «ты»), `en`.
- `status: "Approved"` стоит, чтобы LMS могла выбирать вопросы; **методист вопросы ещё не проверял**.

## Проверка

`node tools/trenajor/build.mjs --check ai`. Просмотр — в просмотрщике уроков, раздел **«Тренажёр»** → ИИ (попытка с эмуляцией LMS и все вопросы
по урокам). Отдельно: `/trainer.html?t=ai&lang=uz`. Замер раскладки всех вопросов — `tools/trenajor/sweep-all.js` (как запускать — в его шапке).
