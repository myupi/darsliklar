# Банк вопросов тренажёра «ИИ» — как писать вопросы

Тренажёр модуля «ИИ» (заказчик, 21.11.2026: «по ии тоже нужно создать такие, там только тесты будут») — тот же тренажёр,
что у HTML и CSS (`tools/trenajor/trenajor.jsx`), но **все вопросы — с выбором из четырёх** (как тесты модуля).
LMS берёт вопросы модуля и случайно выбирает 15 на одну попытку; у каждого вопроса — номер урока (`lesson`), чтобы брать только пройденные.
Миссия — «Заказы студии»: каждый верный ответ сдаёт заказ одного клиента (готовый сайт на доске), неверный — заказ вернулся.

Файл урока: `tools/trenajor/ai/lNN.mjs` (NN = 01…08). Обычный JS-модуль, **без JSX**, `export default [ … ]`.
Проверка: `node tools/trenajor/build.mjs --check --draft ai` (пока готовы не все уроки — `--draft`), без `--draft` — когда готовы все.
Общие правила вопроса (поля, длины, `why` без похвалы, языки) — `tools/trenajor/html/FORMAT.md`, разделы «Один вопрос» и «Что проверяем».

## Сколько

- Уроки 1–7 — по **18** вопросов с выбором (`q01`…`q18`), урок 8 (финальный проект, повторение всего модуля) — **21**.
- id — `ai_lNN_qKK`. Сложность в уроке: примерно 6 `easy`, 8 `medium`, 4 `hard` (в уроке 8 — 6/10/5).
- Других типов (`input`, `build`, `bug`, `tap`) в «ИИ» нет. `mono` не ставить (варианты — слова, не код).

## Картинка вопроса `vis: { ai: { … } }`

Как в тестах модуля (`tools/aitest/kit.jsx`: `AqPrompt`, `AqMsg`, `AqSite`) и в уроках: светлое поле промпта с метками формулы,
сообщение клиента и сайт, который «собрал ИИ», в окне Chrome. На ноутбуке промпт слева, сайт справа; на телефоне — друг под другом
(на маленьком — переключатель «Prompt / Sayt»). Любая часть необязательна, но хотя бы одна нужна.

```js
vis: { ai: {
  msg: { who: T('Mijoz', 'Клиент', 'Client'), text: T('«…»', '«…»', '“…”') },     // сообщение клиента (облачко)
  prompt: [                                                                        // поле промпта, 1–8 строк
    { q: 0, t: T('Futbol turniri sayti', 'Сайт футбольного турнира', 'A football tournament site') },
    { q: 1, t: null },                                                             // пустая строка — «…» (что вписать?)
    { q: 2, t: T('…', '…', '…'), hl: true },                                       // hl — строка обведена оранжевым
    { lab: '2-prompt', c: '#475569', bg: '#F1F5F9', t: T('…', '…', '…') },         // своя метка (урок 7: 1-prompt, 2-prompt)
  ],
  site: { … },                                                                     // сайт в окне Chrome, см. ниже
  focus: '.goal',                                                                  // если сайт не влез — видна часть от этого блока
} }
```

- `q` — номер вопроса формулы (метка и цвет — как в уроках):
  `0` Nima? / Что? / What? (оранжевый) · `1` Nega? / Зачем? / Why? (фиолетовый) · `2` Kim uchun? / Для кого? / For whom? (бирюзовый) ·
  `3` Ichida nima? / Что внутри? / What’s inside? (розовый) · `4` Ko'rinishi? / Как выглядит? / How it looks? (зелёный) ·
  `5` Qanday ishlaydi? / Как ведёт себя? / How it behaves? (янтарный) · `6` Qoidalar? / Какие правила? / What rules? (малиновый).
- Любой текст — строка (одинаковая на всех языках) или `{ uz, ru, en }`. В файле удобно: `const T = (uz, ru, en) => ({ uz, ru, en });`.
- Строка промпта — коротко, как пишет ученик в уроке (до ~60 знаков). Промпт урока N использует только вопросы формулы уроков 1…N
  (урок 1 — Nima? и Nega?, урок 2 — + Kim uchun?, урок 3 — + Ichida nima?, урок 4 — + Ko'rinishi?, урок 5 — + Qanday ishlaydi?,
  урок 6 — + Qoidalar?; урок 7 — «1-prompt», «2-prompt», «3-prompt» своими метками; урок 8 — вся формула).

### Сайт `site` — тот же вид, что собирает ИИ в уроках и тестах модуля

Ширина страницы 600 px (телефон — 360), окно уменьшает её целиком. Поля — как у `AqSite` (`tools/aitest/kit.jsx`, комментарий перед ним):

```js
site: {
  title: T('Shaxmat turniri', 'Шахматный турнир', 'Chess tournament'),   // название: логотип в меню, заголовок баннера, вкладка
  em: '♟️',                                                              // значок у логотипа
  c: '#334155', c2: '#0F172A', bg: '#E2E8F0',                            // главный цвет, второй (тёмный), фон раздела цели
  nav: [T(…), T(…), T(…)],                                               // 3 пункта меню
  badge: T(…), sub: T(…), cta: T(…),                                     // плашка над заголовком, подзаголовок, главная кнопка
  cards: [{ ic: '🏆', h: T(…), p: T(…) }, …],                             // 2–3 карточки под баннером
  goal: { h: T(…), fields: [T(…), T(…)], btn: T(…) },                    // раздел цели: форма записи / заказа
  foot: T('Barcha huquqlar himoyalangan.', 'Все права защищены.', 'All rights reserved.'),
}
```

Необязательно (по теме урока, как в тестах `tools/aitest/l02…l07.jsx`):
- аудитория (урок 2): другой облик — `font`, `dark`, `big: true` (крупно и без меню — для пожилых, как в уроке), свои `cards` (интересы), `badge` («Bolalar uchun»);
- блоки (урок 3): `blocks: [{ h, items: [{ ic, t, p, guess }], mark }]` — `p` — цена/время, `guess: 'Taxmin'` — ИИ выдумал; `info: [{ t, guess }]` — строка сведений;
- вид (урок 4): `radius` (px), `shadow: 'big' | 'none'`, `heroBg: 'linear-gradient(…)'`, `btn` / `btnFg` — цвет кнопок, `font`, `dark`;
- поведение (урок 5): `cursor: 'hover' | 'click'` над главной кнопкой, `ctaHot: { bg, fg, scale }` — кнопка под мышкой, `ctaBig` — огромная кнопка,
  `toast` — сообщение после нажатия, `mobile: true` — телефон (☰ вместо меню), `bottomBtn` — кнопка внизу экрана телефона;
- правила (урок 6): `extras: { popup, sale, chat }` — что ИИ добавил сам (окно подписки, «−50%», чат), `oneBtn` — одна кнопка, `info` с `guess`;
- метки (уроки 3–8): `marks: { hero: { t, c }, cta: { t, c }, info: { t, c }, extras: { t, c } }`, у блока и у `goal` — свой `mark` — цветная метка
  на сайте («Nima?» — какая строка промпта что дала; «O'zi o'zgartirdi» — ИИ сам поменял, урок 7). Цвета меток — цвета формулы выше.
- `noFoot: true` — без подвала (сайт короче).
- `layout` — раскладка сайта (21.11.2026, заказчик: «все однообразные… шаблонные»): `split` / `split2` (текст и иллюстрация рядом), `poster` (крупный заголовок слева), `soft` (мягкий фон, баннер-карточка), `band` (светлый баннер с цветной полосой), `photo` (узор значков и плашка с текстом), `center` (прежний шаблон). Обычно не ставить: движок сам даёт каждому сайту свою раскладку (по цветам и значку, одинаково на трёх языках); сайт «Sizning loyihangiz» — всегда `center`. Раскладка меняет только оформление: новых блоков, цифр и фактов она не добавляет, украшения — только значки, которые уже есть на сайте.

Сайт — как его честно собрал бы ИИ урока из промпта вопроса (тот же цвет, блоки в написанном порядке, «Taxmin» там, где данных не было).
Не делать сайт длиннее нужного: что не важно для вопроса — не ставить. Если важная часть внизу — `focus: '.goal'` (`.cards`, `.blk`, `.info`, `.foot`).

## Что проверяем

- Главные мысли уроков модуля — по сценариям `docs/scenarij-ai-0N-*.md` и самим урокам `lessons/ai/0N-*.jsx`; формула
  «Nima? Nega? Kim uchun? Ichida nima? Ko'rinishi? Qanday ishlaydi? Qoidalar?», затем «2-prompt: что + как, qolganini o'zgartirma».
- Каждый вопрос — **одна главная мысль**. Типы вопросов чередовать: «какая строка промпта точнее?», «какая строка дала этот сайт?»,
  «что вписать в пустую строку?», «какой промпт подходит сообщению клиента?», «почему ИИ сделал так?», «что изменится на сайте, если…»,
  «чего не хватает в промпте?», «какой второй промпт исправит…».
- Неверные варианты — настоящие ошибки учеников из урока (расплывчато: «chiroyli bo'lsin», «zo'r sayt»; не та строка формулы;
  «hammasi tushunarli»; второй промпт без «qolganini o'zgartirma»; «что» без «как») и **не короче** верного.
- Только материал этого урока и прошлых. Финальный 8 — вся формула и улучшение, сайт целиком.
- Не повторять вопросы тестов модуля (`tools/aitest/lNN.jsx`, по 5 на урок): тема та же, ситуация, клиент и сайт другие.
- Ситуации — заказы клиентов студии: кафе, турниры, кружки, магазины, лагерь, библиотека, зоопарк, музыкальная школа, ярмарка… (не только из тестов).
- Картинка — примерно у 2/3 вопросов урока; вопрос без картинки — про понятие («Что такое целевая аудитория?») или про короткую строку в самом вопросе.

## Языки

Узбекский первым и живой речью, «Siz», апостроф только ASCII `'`; русский на «ты», без рода; английский простой. Смысл и варианты — в одном порядке.
Словарь модуля (как в уроках): **sun'iy intellekt** / **ИИ** / **the AI** (по-узбекски всегда полностью, без «SI» и «AI»), **prompt** / **промпт**, **qator** — строка,
**mijoz** — клиент, **buyurtma** — заказ, **maqsad** — цель, **auditoriya** / **целевая аудитория**, **blok**, **ko'rinish**, **taxmin** — догадка ИИ,
**majburiy** — обязательно, **mumkin emas** — нельзя, **qolganini o'zgartirma** — не меняй остальное. Метки формулы — как выше.
Перед работой прочитать `.claude/skills/uzbekcha/SKILL.md` и `references/lugat.md`; как говорят уроки модуля — тексты в `lessons/ai/0N-*.jsx`.
