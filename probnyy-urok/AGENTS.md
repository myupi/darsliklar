# Пробный урок Junior IT — инструкция для агента (Antigravity / Gemini)

Проект — React + Vite, 6 слайдов пробного урока (описание — `README.md`). Код готов и работает.
**Задача агента — сгенерировать недостающие иллюстрации и положить их в нужные места.** Код менять не нужно:
каждая картинка уже имеет свой слот и встанет на страницу сама, как только файл появится.

## Что уже есть (16.11.2026)

**Все 29 картинок на месте:** 8 главных — от Gemini; значки приложений, обложки «Математика» и «IT English», подарки
CoinShop и герои веб-студии — с сайта Junior IT (`from: 'junior'`); обложки «Kids» и «Веб» нарисованы в SVG
(`from: 'svg'`, `src/img/course-kids.svg`, `course-web.svg`). Значки Roblox / Minecraft / футбол от Gemini — про запас в
`src/img/_gemini/`. Генерировать нужно только по прямой просьбе заказчика — например, чтобы заменить картинку.

## Короткое задание (можно вставить агенту как есть)

> Прочитай `probnyy-urok/AGENTS.md`. Сгенерируй все иллюстрации из `probnyy-urok/src/art.js` в общем стиле

## Правила генерации

1. **Промпт = `prompt` слота + `STYLE`.** Плюс образец стиля `src/img/_ref/style-boy.webp` (2D-мультяшная графика,
   жирный контур, тёплый свет с оранжевой каймой). Все картинки — в одном стиле.
2. **Один и тот же персонаж — одинаковый.** Ментор (`mentor`) и куратор (`curator`) — разные люди; ребёнок в `age-kids` и
   подросток в `age-teens`, `final-consume`, `final-create`, `course-web` — можно одного и того же подростка.
3. **Без текста, букв, цифр, логотипов и водяных знаков** в том, что генерируется (значки приложений и подарки уже взяты с
   сайта Junior IT — их не трогать).
4. **Фон — по виду слота (`kind`):**
   - `tile` — квадрат на весь кадр со своим фоном из промпта (углы обрежет сайт; прозрачность не нужна);
   - `portrait` — квадрат со своим фоном; лицо в центре **верхней половины** (сайт показывает его в круге);
   - `cover` — широкая картинка на весь кадр (16:10), без важного у самых краёв;
   - `onwhite` — предмет на **чисто белом** фоне `#FFFFFF` (сайт «растворяет» белое на светлой карточке); без серых виньеток;
   - `asis` — файл показывается целиком как есть (подарки с сайта Junior IT).
5. **Размер — `size` слота** (например 512×512). Генерировать можно крупнее (1024), потом **уменьшить до `size`** и
   сохранить в WebP (качество ~82). Файл — **не больше ~250 КБ**. Если WebP сделать нечем — PNG того же размера
   (например, на macOS: `sips -Z 512 in.png --out src/img/age-kids.png`).
6. Квадратные слоты — строго квадрат; `cover` — 16:10 (640×400, 800×500).

## Проверка

```bash
node probnyy-urok/scripts/art-status.mjs          # какие слоты заполнены, размеры файлов
npm --prefix probnyy-urok run dev                 # http://localhost:5180
```

Если `npm run dev` / `build` падает с кодом 126 («не исполняемый файл» — так бывает в песочнице агента), запускать
Vite через node напрямую (зависимости лежат в `node_modules` корня репозитория, ставить ничего не нужно):

```bash
cd probnyy-urok && node ../node_modules/vite/bin/vite.js            # dev, http://localhost:5180
cd probnyy-urok && node ../node_modules/vite/bin/vite.js build      # сборка в probnyy-urok/dist
```

Открыть нужный слайд сразу: `http://localhost:5180/?slide=N&lang=ru` (N = 1…6, `lang=uz` — узбекский).
Где какая картинка — поле `slide` и `where` в `ART`. Проверить и на ширине телефона (360–390 px): картинки не должны
вылезать за карточки, лица в кругах — по центру.
