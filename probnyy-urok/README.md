# Пробный урок Junior IT

Отдельный React-проект внутри `darsliklar` (16.11.2026). По образцу пробного урока Junior IT
(junior-12-yosh.vercel.app): 6 слайдов, урок ведёт живой ментор — голоса нет.

- **Шапка и низ** — как у образца: логотип, «Слайд N / 6», полоса прогресса, RU / UZ, звуки-отклики;
  внизу «Назад», «Пропустить» (где можно) и главная кнопка.
- **Содержимое** — облик наших уроков: стол в точку, белые карточки, оранжевый CoddyCamp `#FA4F28`,
  строка задания с оранжевой полосой, в практике — тёмный редактор как VS Code и браузер Chrome.

## Слайды

1. Возраст — Kids 8–10 / Teens 11–17, отметка «14+» (только для Teens; Kids её снимает).
2. Три любимых приложения → на чём они написаны.
3. Ментор и куратор, как проходит неделя.
4. Платформа (пример): главная, курсы (Kids, веб, математика с задачей, IT English с карточками), CoinShop — цель-подарок, сертификаты.
5. Практика: «Веб-студия» — слои HTML → CSS → JS, правки в коде сразу в браузере; «Лабиринт» — 3 уровня (шаги, повторы 2× / 3×, прыжок через лаву). Возраст выбирает, какая открыта первой.
6. «Один год — два результата», итог урока, «Я выбираю создавать» → `go.junior-it.uz/login` (`LINK_AFTER` в `src/ui/kit.jsx`).

Выбор ученика хранится в браузере (`localStorage`), перезагрузка не сбрасывает урок; «Пройти заново» — на финале.
Тексты — `src/i18n.js` (uz и ru). Ссылка с параметрами: `?lang=uz&slide=5`.

## Живость (16.11.2026)

- **Junior Coins:** по 5 монет за действие (возраст, 3 приложения, чат, задача, карточки, цель, кнопка JS, уровни лабиринта),
  до 50 за урок; монета летит в счётчик шапки; итог и полоса до цели-подарка — в CoinShop и на финале.
- Плавающие значки по краям стола с параллаксом (широкий экран), объём карточек под мышкой, появление по очереди;
  слайд 2 — «сканер» печатает код выбранных приложений; слайд 3 — живой мини-чат ментора и куратора.
  Всё — `src/ui/live.jsx`.

## Иллюстрации

29 слотов-картинок (`src/art.js`: id, размер, где, промпт; общий стиль `STYLE`, образец — `src/img/_ref/style-boy.webp`).
Файл `src/img/<id>.webp` встаёт на место сам; пока его нет — прежний значок. Что готово — `node scripts/art-status.mjs`.
Инструкция для агента, который генерирует картинки (Antigravity / Gemini), — `AGENTS.md`.

## Запуск

```bash
npm --prefix probnyy-urok run dev     # http://localhost:5180
npm --prefix probnyy-urok run build   # probnyy-urok/dist
```

Зависимости (react, vite, lucide-react) берутся из `node_modules` корня репозитория; для отдельного развёртывания —
`npm install` в этой папке.
